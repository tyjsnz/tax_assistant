# 示例文件（可导入「📥 票据与流水」页面试用）

| 文件 | 说明 |
|---|---|
| `invoices/销项_云图科技_2026Q1.xml` | 数电票（普通发票）XML，销售方为本企业（销项） |
| `invoices/进项_办公用品_2026Q1.xml` | 数电票（专用发票）XML，购买方为本企业（进项） |
| `bank/银行流水_2026Q1.csv` | 招商银行风格流水（收入/支出分列），与上面两张发票可自动匹配 |

用法：进入「📥 票据与流水」→ 上传发票文件 → 上传银行流水 → 点击「自动匹配」→ 勾选确认并入账。
所有数据均为虚构示例，仅用于演示。
