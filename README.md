# 税小智 · 小规模纳税人自主税务填报系统

> 面向**小规模纳税人**（季度含税流水 ＜ 30 万）的本地化税务助手：自动记账、确定性算税、
> 一键生成申报表并导出、申报表截图核对、政策知识库、申报日历提醒，全部 AI 能力使用 **DeepSeek**。
>
> 服务对象示例：XXXX络科技开发有限公司（网络科技 · 小规模纳税人）

> ⚠️ 本系统为辅助工具，算税与申报结果**仅供参考，以主管税务机关核定为准**。
> 正式申报请登录电子税务局完成；涉及重大涉税决策建议咨询专业财税机构。

## 2. 快速开始

### 2.1 环境要求

- macOS / Linux / Windows，Python **3.11+**
- 网络：仅「AI 问答 / 政策问答 / 截图文字理解」需要访问 DeepSeek API；
  **算税、台账、申报表生成、导出全部离线可用**

### 2.2 安装与启动

```bash
cd /Users/shanengzhi/www/2026/prj/tax

# 1) 创建并激活虚拟环境
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 2) 安装依赖
pip install -r requirements.txt

# 3)（可选）生成演示账套：虚构公司 + 全年数据，快速体验完整流程
.venv/bin/python scripts/seed_demo.py --reset

# 4) 启动系统（推荐使用 .venv 内的 streamlit）
.venv/bin/streamlit run ui/streamlit_app.py
```

浏览器访问终端输出的地址（默认 <http://localhost:8501>）。

> 首次进入可点击侧边栏「⚙️ 设置 → 加载示例数据」，立即体验完整流程；
> 多家公司可在侧边栏「当前公司」切换，或在「设置 → 企业信息」新建公司账套。
> 所有示例数据均为虚构，可在设置页一键清空。

### 2.3 命令行方式（可选）

```bash
# 算一笔增值税
.venv/bin/python main.py calc-vat --total 103000 --special 0 --period 2026Q1

# 生成某季度申报表并导出 Excel
.venv/bin/python main.py file --period 2026Q1 --out exports/

# 导入发票与银行流水，并自动确认高置信度匹配入账
.venv/bin/python main.py ingest --invoices "examples/invoices/*.xml" --bank "examples/bank/*.csv" --confirm-score 90
.venv/bin/python main.py pool          # 查看票据池/流水池/匹配概览

# 多公司（账套）与地区
.venv/bin/python main.py companies     # 公司列表（当前公司标记）
.venv/bin/python main.py company-add --name "第二公司" --region yunnan-county-town --switch
.venv/bin/python main.py regions       # 地区预设与城建税税率

# 命令行对话（需 API Key）
.venv/bin/python main.py chat
```

## 3. DeepSeek API Key 配置

系统所有 AI 能力**只使用 DeepSeek**。Key 有三种填写方式，任选其一：

### 方式 A：界面填写（推荐，自主可控）

启动后进入 **⚙️ 设置 → DeepSeek 模型配置**：

1. 填写 API Key（`sk-...`），点击「保存」；
2. 点击「测试连接」，看到 `✅ 连接成功` 即可；
3. 选择模型：`deepseek-chat`（通用，推荐）/ `deepseek-reasoner`（深度推理，较慢）。

Key 只保存在本地 `data/user_settings.json`（文件权限 600），**不会上传、不会写日志、不会进版本库**。
「清除 Key」可随时移除；未配置 Key 时系统进入**离线模式**（算税/台账/申报/日历全部可用）。

### 方式 B：环境变量

```bash
export DEEPSEEK_API_KEY="sk-xxxxxxxx"        # 当前终端会话
```

### 方式 C：`.env` 文件

```bash
cp .env.example .env
# 编辑 .env：DEEPSEEK_API_KEY=sk-xxxxxxxx
```

优先级：**设置页保存的 Key > 环境变量 `DEEPSEEK_API_KEY` > `.env`**。
API 地址默认 `https://api.deepseek.com`（兼容 OpenAI 协议），如有自建网关可在设置页修改 `base_url`。

## 5. 典型工作流：一个季度的自主填报

```text
⓪ 票据/流水导入   「📥 票据与流水」上传数电票与银行流水 → 自动匹配开票与收款 → 确认入账
⓪' 月度工资/个税  「👥 员工与工资」生成工资表 → 重新计算个税（累计预扣）→ 确认并生成凭证 → 导出扣缴辅助表，到扣缴端申报
① 日常记账        台账管理 / AI 助手说一句话（"今天收到云图科技 20,600 元技术服务费，开了普票"）
                  → 自动写入收入台账，推导不含税 20,396.04、税额 203.96，生成分录
② 归集研发费用    费用台账勾选「研发相关」→ 研发辅助账自动归集 → 加计扣除额
③ 季度算税        算税工作台「从台账取数」→ 增值税/附加税/所得税预缴/印花税
④ 生成申报表      申报填报选期间 → 一键生成增值税申报表、所得税预缴表、财务报表、印花税
⑤ 校验与导出      勾稽校验 PASS → 导出 Excel 申报包（含填报指引）→ 下载
⑥ 对照电子税务局  按导出的栏次在电子税务局填报（系统不代替登录、不代替提交）
⑦ 申报后核对      上传申报回执/申报表截图 → 逐栏比对 → 确认无误
⑧ 月结/季结       首页「立即结账」→ 结账前检查清单 → 生成损益结转凭证 → 锁定该期间
⑨ 归档与备份      「📦 归档本期申报包」生成 Excel+PDF+SHA-256 清单；设置页创建数据备份并定期演练恢复
⑩ 审计留痕        算税、分录、申报、结账、归档、备份全过程写入 logs/ 审计日志
```

> 申报渠道：云南省电子税务局（https://etax.yunnan.chinatax.gov.cn），

## 7. 算税口径与政策依据

> 以下参数集中在 `config.py`（`POLICY`）与 `engine/policy_params.py`，按期间匹配，可审计、可更新。

### 7.1 增值税（小规模纳税人，按季申报）

> **政策依据按期间自动匹配**：2023-01-01 ~ 2025-12-31 适用财政部 税务总局公告 2023 年第 19 号；
> **2026-01-01 起《增值税法》施行**，依据切换为《增值税法》及
> [财政部 税务总局公告 2026 年第 10 号](https://szs.mof.gov.cn/zhengcefabu/202601/t20260131_3983036.htm)
> （2023 年第 19 号自 2026-01-01 起停止执行）。系统对每笔算税/申报结果标注**当前期间**的依据。

| 项目 | 口径（2026—2027 年） | 依据 |
|---|---|---|
| 征收率 | 3% 减按 **1%**（**不含销售、出租不动产及转让土地使用权**） | 2026 年第 10 号公告 第三条第三项第 6 目 |
| 起征点 | 季度销售额（不含税）≤ **30 万元** 免征；按月为 10 万元；按次（日）1,000 元 | 2026 年第 10 号公告 第一条 |
| 免税判定基数 | **全部销售额（含专票）**，可用 `limit_basis="ordinary"` 切换为仅普票口径 | 同上（合计销售额口径） |
| 专票部分 | 不免税，按 1% 缴纳 | 同上 |
| 超限 | 全部销售额按 1% 缴纳，不再免税 | 同上 |
| 应纳税额减征额 | 应征销售额 × (3% - 1%) = × 2%（申报表第 22 栏） | 同上 |
| 预缴 | 预缴地实现价款/预收款合计达到起征点的，减按 **1% 预征率**预缴 | 2026 年第 10 号公告 第三条第三项第 6 目 |
| 附加税费 | 实缴增值税 × 12%（城建 7% + 教育 3% + 地方教育 2%）× 六税两费减半 50% = × 6% | 财政部 税务总局公告 2023 年第 12 号（继续有效） |

计算示例（规范文档用例）：季度含税 103,000 元 →
不含税 101,980.20 ≤ 300,000 → 免征增值税 1,019.80 元，附加税费 0，**本期应纳税费合计 0**。

### 7.2 企业所得税

- **小型微利企业**：年应纳税所得额 ≤ 300 万、从业人数 ≤ 300 人、资产总额 ≤ 5,000 万、非限制/禁止行业；
  减按 25% 计入应纳税所得额、按 20% 税率 → **实际税负 5%**（2023 年第 12 号，至 2027-12-31）。
- 季度预缴：按**本年累计**实际利润额 − 累计研发加计扣除 → 累计应纳税所得额 × 税率 − 本年已预缴。
- 年度测算：会计利润 + 纳税调整 − 研发加计扣除 = 应纳税所得额；亏损不缴税并提示结转。

### 7.3 研发费用加计扣除

- 未形成无形资产：按实际发生额的 **100%** 加计扣除（财政部 税务总局公告 2023 年第 7 号）。
- 形成无形资产：按无形资产成本的 **200%** 税前摊销（本系统按 10 年摊销估算）。
- 其他相关费用限额 =（人员人工+直接投入+折旧+无形资产摊销+新产品设计费）× 10% ÷ (1-10%)。
- 归集范围：人员人工、直接投入、折旧、无形资产摊销、新产品设计费、其他相关费用；
  房租等不属于归集范围，自动剔除并提示。

### 7.4 印花税

技术合同/买卖合同/建设工程合同/运输合同 0.3‰、借款合同 0.05‰、租赁合同 1‰、
产权转移书据 0.5‰、营业账簿 0.25‰；小规模纳税人按「六税两费」**减半**征收。

### 7.5 申报日历

增值税及附加、企业所得税预缴、财务报表：季度终了后次月 **15 日**；
个税扣缴：次月 **15 日**；汇算清缴：次年 **5 月 31 日**；工商年报：次年 **6 月 30 日**。
遇周末自动顺延至工作日，法定节假日以税务机关公告为准；系统按 7/3/1 天提醒（并显示 15 天提醒窗口）。

### 7.6 政策版本化与维护

政策不是写死在代码里的“魔法数字”，而是按「**期间 → 版本 → 依据列表**」维护：

```text
2023-01-01 ~ 2025-12-31  财政部 税务总局公告2023年第19号（增值税暂行条例时期）
2026-01-01 ~ 2027-12-31  《增值税法》+ 财政部 税务总局公告2026年第10号（衔接公告）
```

- 每个版本包含：生效区间、参数覆盖、依据列表（标题 / 文号 / 条款 / 生效日 / 失效日 / 原文链接 /
  税种 / 备注）、停用文件清单。
- 算税结果、申报表 bundle、AI 回答均引用**当前期间**的依据，不会出现“算对数字、写错依据”。
- 新增政策时按 [政策维护手册](docs/POLICY_MAINTENANCE.md) 的 Runbook 操作：核对原文 → 追加版本 →
  同步知识库 → 补边界回归测试 → 全量测试。
- 已验证区间（2023—2027）之外会给出明确告警，提醒核对最新政策。

### 7.7 票据与流水支持的文件格式

| 类型 | 格式 | 解析方式 | 说明 |
|---|---|---|---|
| 数电票 | **XML** | 标准库 XML + 字段别名表 | 最可靠，推荐从电子发票服务平台下载 XML |
| 数电票 | **OFD** | zip 解包后扫描内嵌 XML | 常见下载格式，自动查找发票 XML |
| 数电票 | **PDF** | pypdf 提取文本 + 中文正则 | 纯图片 PDF 无法识别时改用手动录入 / XML |
| 银行流水 | **CSV** | 自动尝试 UTF-8 / GBK / GB18030 | 支持收入/支出分列、单金额+方向、正负金额三种 |
| 银行流水 | **XLSX** | openpyxl（表头前 5 行探测） | 常见网银导出格式，列名自动识别、可手动映射 |

匹配规则（确定性、可解释）：方向一致（销项↔收入、进项↔支出）+ 金额差 ≤5% + 日期差 ≤15 天 +
对方名称相似度，综合打分 0–100，低于阈值不推荐；确认后按发票金额写入台账并生成凭证，
金额差异会在提示中给出。示例文件见 `examples/`。

### 7.8 结账、归档与备份

| 动作 | 做了什么 | 产物 |
|---|---|---|
| **月结/季结** | 结账前检查（凭证借贷平衡、待匹配票据、重复发票、上期是否已结、政策区间等）→ 生成损益结转凭证（收入类结转本年利润、费用类结转本年利润）→ 期间状态置「已结账」并生成**数据快照哈希** | `periods` 表 + 结转凭证 + 快照 |
| **期间锁** | 已结账期间禁止新增/修改/删除收入、费用、研发辅助账、凭证；禁止匹配入账；禁止倒记更早期间 | 写入被拒绝并给出中文提示 |
| **反结账** | 仅最近一个已结账期间可反结；删除自动生成的结转凭证，状态回「未结账」 | 审计日志 |
| **申报包归档** | 生成 Excel 申报包 + PDF 申报表 + `manifest.json`（逐文件 SHA-256、政策依据、校验结论、版本） | `data/archive/{期间}/` |
| **归档校验** | 重新计算文件哈希并与 manifest 比对，检测篡改/缺失 | 校验报告 |
| **数据备份** | 全部台账 CSV（+日志可选）打包为 zip，附 manifest 哈希；**不包含 API Key、上传文件、旧备份** | `data/backups/backup_*.zip` |
| **恢复** | 默认 dry-run 预览（表/条数/完整性）；确认后先自动安全备份，再按白名单校验哈希后原子恢复 | 恢复报告 + 安全备份 |

> 原则：**结账后不改账**；要改先反结账。归档是只读快照，备份可演练恢复。
> 所有哈希基于 SHA-256 + 规范化 JSON，任何环节被改动都能被发现。

### 7.9 多公司（多账套）与地区参数化

**目录布局**

```text
data/
├── companies.json                 # 公司注册表（active = 当前激活公司）
├── schema.json                    # 数据布局版本（升级时自动迁移）
├── user_settings.json             # 全局设置（API Key/模型，不随公司切换）
├── logs/                          # 全局审计日志
└── companies/{company_id}/        # 每家公司独立账套
    ├── income_ledger.csv …        # 全部台账、期间、归档索引
    ├── archive/                   # 申报包归档
    └── backups/                   # 数据备份
```

* 侧边栏可一键切换公司；**切换只切 `config.DATA_DIR`**，台账/期间/归档/备份随之隔离；
* 新建公司自动初始化独立账套；删除默认软删除（移动到 `companies/_deleted/`），且不能删除当前/唯一公司；
* **首次升级自动迁移**：旧版根目录 `data/*.csv` 会移动到 `companies/main/`，旧设置中的企业信息写入首家公司，数据不丢；
* 地区预设决定城建税税率（市区 7% / 县城·镇 5% / 其他 1%），附加税费 = 增值税 ×（城建 + 教育 3% + 地方教育 2%）× 六税两费减半；算税、申报表、归档自动引用当前公司地区。

### 7.10 个人所得税扣缴（工资薪金，累计预扣法）

```text
员工档案（含专项附加扣除） → 月度工资表 → 累计预扣法算税 → 工资计提/发放凭证 → 扣缴申报辅助表（Excel）
```

**计算口径**（`engine/iit.py`，确定性代码）：

- 本期应预扣税额 = 累计应纳税所得额 × 预扣率 − 速算扣除数 − 累计已预扣税额；
- 累计应纳税所得额 = 累计收入 − 累计减除费用（5,000 元/月）− 累计专项扣除（三险一金）− 累计专项附加扣除 − 累计其他扣除；
- 预扣率表：3% / 10% / 20% / 25% / 30% / 35% / 45%（速算扣除数 0 / 2,520 / 16,920 / 31,920 / 52,920 / 85,920 / 181,920）；
- 专项附加扣除（2023 年提高标准后）：子女教育 2,000 元/月/孩、3 岁以下婴幼儿照护 2,000 元/月/孩、继续教育 400 元/月（或 3,600 元/年）、住房贷款利息 1,000 元/月、住房租金 1,500/1,100/800 元/月、赡养老人 3,000 元/月（非独生分摊 ≤1,500）、大病医疗 80,000 元/年（仅汇算）；
- **2026 年扣缴端升级**：5,000 元/月减除费用按**实际申报月份**累计，未申报月份额度作废——系统对零工资月份提供「一键零申报」，并在算税时提示漏申报风险；补发工资按实际所属月份处理（`零申报` + `已申报` 状态驱动累计口径）。

**凭证**：计提（借 管理费用—工资薪金 / 研发支出—人员人工，贷 应付职工薪酬）+ 发放代扣（借 应付职工薪酬，贷 银行存款 / 其他应付款—社保、公积金 / 应交税费—应交个人所得税），借贷平衡、幂等。

**扣缴申报辅助表**：主表 11 行（收入/免税/减除/专项扣除/专项附加/其他/应纳税所得/应预扣/已预扣/应补退/人数）+ 员工明细 + 政策依据与操作步骤，可导出 Excel。**实际申报仍在自然人电子税务局（扣缴端）完成**，系统不代申报。

### 7.11 企业所得税汇算清缴辅助（年度）

```text
年度台账汇总 → 录入限额类实际发生额 → 纳税调整（自动 + 手工）→ 亏损弥补
→ 汇算测算（应纳税所得额/应纳所得税/应补退）→ 年度申报辅助表（Excel）→ 检查清单
```

| 项目 | 规则（确定性代码） | 依据 |
|---|---|---|
| 业务招待费 | 发生额 × 60% 与营业收入 × 5‰ 孰低 | 企业所得税法实施条例第 43 条 |
| 广告费和业务宣传费 | 营业收入 × 15%（超出可结转） | 实施条例第 44 条 |
| 职工福利费 / 教育经费 / 工会经费 | 工资薪金总额 × 14% / 8% / 2% | 实施条例第 40/42/41 条 |
| 研发费用加计扣除 | 未形成无形资产 100% 加计 | 财政部 税务总局公告 2023 年第 7 号 |
| 亏损弥补 | 一般企业 5 年 | 企业所得税法第 18 条 |
| 小型微利企业 | 应纳税所得额 ≤300 万等条件，实际税负 5% | 财政部 税务总局公告 2023 年第 12 号 |

* 年度输入（业务招待费/广告费/三项经费/从业人数/资产总额/预缴税额/会计利润覆盖等）保存在
  `annual_settlements` 表，可按年度反复测算；
* 纳税调整 = 限额类自动计算 + 手工调整清单（罚款、免税收入、不征税收入等）；
* 亏损台账记录亏损年度、可弥补额、已弥补、到期年度，按到期先后自动测算本年度可弥补额；
* 年度申报辅助表：A 类主表关键行次 + 纳税调整明细 + 亏损弥补明细 + 政策依据/资料留存 + 操作步骤，可导出 Excel；
* **实际年度申报仍在电子税务局完成（次年 5 月 31 日前）**，系统只做数据准备与核对。

### 7.12 离职与申报纠错（离职后多申报 / 个税异议申诉）

员工离职后忘记停做工资、离职后月份仍申报个税，是不少小公司会踩的坑。员工可能在个人所得税 APP
对「任职受雇信息」或「收入纳税明细」发起异议申诉，**即使事后撤销申诉，错误申报数据仍需更正**。

系统提供从“发现 → 测算 → 操作单 → 留痕”的闭环：

* **异常扫描**：自动找出「已登记离职日期、但离职月份之后仍有工资/个税申报」的员工，列出月份、收入、已预扣税额；
* **更正测算**：以离职月份为界，离职后月份收入/专项扣除/个税改为 0，按**累计预扣法逐月重算**，
  得出预计多缴（可退）或少缴（需补）个税；
* **联动影响**：估算多列工资的企业所得税调增（小微 5% / 一般 25%）、社保公积金个人部分退费参考；
* **操作单**：生成《离职员工多申报更正操作单》Excel，包含扣缴端逐月更正步骤、电子税务局退税路径、账务/企税/社保联动、留痕清单；
* **申诉台账**：登记员工申诉类型、日期、状态（待处理/已沟通/已撤销/已更正/已关闭）、撤销日期与处理结果；
* **知识库与 AI**：新增《离职员工多申报工资与个人所得税异议申诉处理》政策指引；AI 助手新增「离职与申报纠错」意图与工具，可直接扫描并生成方案；
* **零基础指引**：处置页内置「3 步走」说明，操作单同时导出 Excel 与可打印 PDF（九步操作 + 留痕清单）。
* **勾选式进度清单**：九步操作可逐项打勾、显示完成百分比，防止漏步；
* **离职补偿金分项测算**：经济补偿金参考（劳动合同法 47 条，3 倍社平封顶/12 年）+ 一次性补偿个税（3 倍社平以内免征、超出单独计税）+ 税后到手；
* **操作示意图与视频脚本**：新增《扣缴端离职更正操作示意图 + 视频分镜脚本》与打印清单。

入口：「👥 员工与工资」→「🧯 离职与纠错」；CLI：`python main.py payroll-scan`、`python main.py correction-plan --employee <员工编号>`。

> 员工撤销申诉 ≠ 更正申报；实际更正仍在自然人电子税务局（扣缴端）完成，系统只做测算与操作指引。

## 8. 安全、隐私与审计

1. **数据不出本地**：台账、设置、导出文件全部位于项目 `data/`（按公司账套隔离）、`logs/`、`exports/`；
   除 AI 问答/政策问答/截图文字理解会把必要文本片段发送给 DeepSeek 官方 API 外，无任何数据上传。
2. **API Key 安全**：仅保存在 `data/user_settings.json`（chmod 600），界面只显示脱敏值；
   审计日志不记录 Key；`.env` 与用户设置已在 `.gitignore` 中。
3. **客户信息脱敏**：设置页开启「隐私模式」后，AI 上下文中客户名可脱敏（客户A/客户B…）。
4. **审计日志**（`logs/`）：算税记录、分录生成、申报填报、政策检查、用户操作，逐条带时间戳。
5. **行为约束**：系统不代替登录电子税务局、不代替提交申报、不做税务鉴证、不做转账建议；
   所有算税/申报输出均附「仅供参考，以主管税务机关核定为准」。
6. **备份与恢复**：设置页「数据管理」创建 zip 备份（含 manifest 哈希，**不含 API Key/上传文件**），恢复默认 dry-run 预览、执行前自动安全备份；归档包可随时校验完整性。

## 11. 与《报税 Agent 开发规范》的差异说明

为更贴合现行税务口径与工程实践，在规范文档基础上做了以下**已文档化**的调整：

| 项 | 规范文档 | 本系统实现 | 原因 |
|---|---|---|---|
| 免税判定 | 仅按「普票+未开票」不含税 ≤ 30 万判断 | 默认按**全部销售额（含专票）**判断，同时保留 `limit_basis="ordinary"` 兼容规范口径 | 2023 年第 19 号 / 2026 年第 10 号均以「合计销售额」为口径；两种口径均在测试中覆盖 |
| 政策依据 | 固定引用 2023 年政策 | 按期间版本化：2023—2025 引用 2023 年第 19 号，2026 年起引用《增值税法》+2026 年第 10 号 | 增值税法 2026-01-01 施行，19 号公告停止执行（2026 年第 10 号第六条） |
| 专票免税额度内附加税 | 附加税 = 0 | 专票缴纳增值税时按 12%×50% 计征附加税，并提示教育费附加免征情形 | 附加税以实际缴纳增值税为计税依据，规范文档为简化处理 |
| 分录存储 | 单表 `journal_entries.csv`（借贷单行） | 拆为凭证头 `journal_entries.csv` + 分录行 `journal_lines.csv` | 支持「一借多贷」的完整凭证 |
| LLM / 框架 | 腾讯混元 API + LangChain | **全部使用 DeepSeek**，`requests` 直连 OpenAI 兼容接口，不引入 LangChain | 用户要求 AI 均用 DeepSeek，减少依赖 |
| OCR | PaddleOCR / Tesseract | macOS Vision 本地 OCR（零依赖、中文效果好）+ tesseract 兜底 + 手动粘贴；DeepSeek 负责文字理解与栏次映射 | DeepSeek 官方 API 无视觉能力；本机 tesseract 无中文语言包 |
| 政策知识库 | 向量库 RAG | 本地 Markdown + BM25 关键词检索 + DeepSeek 作答引用（无向量库依赖） | 政策文件少，检索更可控、可解释、离线可用 |
| 数据存储 | SQLite + CSV | CSV 台账（原子写入 + 备份 + 审计日志） | 轻量、可直接用 Excel 打开核对 |
