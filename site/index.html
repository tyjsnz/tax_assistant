常见问题

你可能关心的事

没有会计基础，真的能自己报税吗？

能。系统把每个税种做成向导式页面，算税由确定性代码完成，AI 助手负责用大白话解释每一步。你只需要按提示录入收入、费用和发票信息，生成申报表后到电子税务局核对提交。

我的财务数据安全吗？

数据默认只保存在本机 data/ 目录（CSV），不会上传到任何云端；API Key 只存本地并脱敏显示；备份文件带 SHA-256 校验。项目开源，代码可审计。

必须购买 DeepSeek API 吗？

不必须。不填 Key 时会自动进入离线模式，算税、台账、申报表、结账、归档、备份全部可用；填写 Key 后可使用 AI 对话解释与政策问答（按量计费，费用很低）。

系统能直接帮我完成申报吗？

不能。系统生成申报表与辅助资料、标注来源与口径，实际申报与缴款仍需在电子税务局/扣缴端完成。本工具为辅助软件，不构成税务鉴证，结果以主管税务机关核定为准。

支持几家公司？多地区税率？

支持多公司（多账套）切换，每家公司数据独立；内置城建税 7%/5%/1% 地区预设，附加税费自动计算。
