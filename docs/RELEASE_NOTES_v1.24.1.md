# v1.24.1 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.24.1`

## 修复：一键季度流水线遇到已结账月份

v1.24.0 的季度流水线在生成工资表时，如果某个月已结账，会报错并中断该步骤。

v1.24.1：

- 预览时提示“该期间已结账，流水线会跳过工资生成”；
- 执行时**自动跳过已结账月份**，继续后面的月份与申报包；
- 结果中标注“已结账，跳过工资生成”，不会修改锁定数据。

## 验证

- 临时账套实测：结账月份跳过、其余步骤成功，`ok=True`；
- 全量 822 项离线测试通过。

> ⚠️ 已结账期间需先反结账才能修改；流水线不会自动反结账。
