# v1.44.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.44.0`

## 修复：生成新月份工资表全是 0

问题：从 2026-10 申报表导入工资草稿后，生成 2026-11 工资表时，
新行只从员工档案取专项附加，收入/社保/公积金都是 0，需要手工重填。

修复：生成新月份工资表时，自动取该员工**最近一期**工资行作为底稿，带出：

- 应发工资；
- 奖金；
- 补贴；
- 个人社保；
- 个人公积金；
- 专项附加扣除；
- 其他扣除。

累计收入、累计税额、实发工资**归零**，需核对后重算；备注显示“以上月 YYYY-MM 工资为草稿基础”。

## 真实数据验证

使用「昆明霖尚科技有限公司_综合所得申报_202610.xlsx」：

1. 导入 2026-10 工资草稿 10 人；
2. 生成 2026-11 工资表；
3. 10 人应发工资全部自动带出：4300、4850、4700、4850、4850、4850、4680、4900、5000、4780；
4. 累计数均为 0，等待核对重算。

## 说明

- 新员工/上月没有工资记录时仍从 0 开始；
- 带出的是草稿，用户可逐项修改；
- 不会自动复制上月税额，避免累计预扣错误。

## 验证
