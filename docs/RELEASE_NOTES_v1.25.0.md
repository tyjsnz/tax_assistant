# v1.25.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.25.0`

## 亮点：📬 发票归集（本地文件夹 + 邮箱 IMAP）

新增第 17 个页面「📬 发票归集」，解决“电子发票怎么自动进系统”的问题。

### 1. 本地文件夹归集

- 把电子税务局「全量发票查询/税务数字账户」导出的 PDF/OFD/XML 放进一个文件夹；
- 系统扫描、解析、去重、入发票池，并可自动生成匹配建议；
- 重复文件按哈希跳过，不会重复入账。

### 2. 专用邮箱 IMAP 归集

- 配置收票邮箱的 IMAP 服务器/账号/授权码；
- **只读拉取**附件，不删除邮件、不标记已读；
- 附件保存到本地，解析后导入；
- 授权码只保存在本机数据目录（600 权限），不上传。

### 3. 归集日志

记录来源、文件名、哈希、导入/跳过数量与错误，便于核对“哪些票进来了、哪些没进来”。

## 为什么不做“直接登录电子税务局自动下载”

电子税务局没有面向本地工具的公开 API；自动登录涉及实名认证、验证码、CA/账号安全和合规责任。
因此采用两条合规路径：**手工导出到文件夹** + **专用邮箱 IMAP**；第三方开放平台 API 可作为后续可选适配。

## 变更

- 侧边栏 17 个页面；全量离线测试 **827 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 发票归集只负责“拿到并解析”，是否入账/扣除仍需按发票合规判断与人工复核。
