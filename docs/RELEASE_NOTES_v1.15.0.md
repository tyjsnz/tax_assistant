# v1.15.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.15.0`

## 亮点：问答知识库闭环（候选 → 审核 → 检索 → 注入）

v1.14 已记录每次问答；v1.15 让它们真正"越用越懂这家公司"：

### 1. 一键沉淀

- 悬浮 AI 回答下方新增 **「📌 存为知识」**：把这条问答转为**候选**知识；
- 也可以在「📚 政策知识库 → 我的问答知识库」从最近问答中挑选。

### 2. 人工审核发布

- 候选 → **✅ 发布 / 🚫 驳回 / ⏳ 标记过期**；
- 只有「已发布」的知识才参与回答，避免把错误答案当真理；
- 按公司账套隔离，不上传、不跨公司共享。

### 3. 检索与上下文注入

- 本地中文 bigram 相似度检索（无需向量库）；
- **高置信**：直接本地回答，标注「🗂️ 已审核知识库」；
- **中置信**：把已审核问答作为参考注入 LLM 上下文，并在系统提示中注明“仅参考、需结合现行政策”；
- **政策版本变化**后旧知识自动失效，避免拿过期口径回答。

### 4. 对小白用户

- 不需要理解 embedding / 向量库：只要点“发布/驳回/存为知识”；
- 回答来源标签清楚：📗 本地计算 / ♻️ 缓存 / 🗂️ 已审核知识库 / 🤖 AI 流式；
- 未命中时仍可正常回答，并提示“已记录，可在知识库中完善”。

## 变更

- 全量离线测试 **790 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 知识库条目仍需人工审核；所有回答仅供参考，以主管税务机关核定为准。
