# v1.7.0 发布说明（Release Notes）

发布日期：2026-11-10 · 标签：`v1.7.0`

> 小规模纳税人自主税务填报系统 · 本地优先 · 确定性算税 + DeepSeek 辅助

## 亮点

- **补齐年度/低频申报辅助**：工商年报数据准备表、残疾人就业保障金测算（分档减缴、30 人以下免征）、
  社保/残保金申报提醒与资料清单；
- **开源 Beta 就绪**：完整文档集、一键演示账套、发布检查清单、Issue/PR 模板、CI；
- **仓库脱敏**：`data/` 账套数据不再入库（首次启动自动生成，演示数据用脚本生成），避免真实数据误提交。

## 新增

### 工商年报 / 残保金（P1-D）
- 「📋 申报填报 → 工商年报 / 残保金」折叠区、CLI、Agent 工具；
- 工商年报数据准备表：企业基本信息、资产状况（台账估算，需与财报核对）、从业人数、
  校验项与 gsxt 操作步骤，可导出 Excel；
- 残保金测算：1.5% 法定比例、分档减缴（1%~1.5% 按 50%、低于 1% 按 90%）、
  30 人（含）以下免征、年平均工资 2 倍封顶提示，可导出 Excel；
- 申报日历新增：社会保险费（每月 25 日提醒）、残疾人就业保障金（9 月 30 日提醒，以当地公告为准）；
- 知识库新增：残疾人就业保障金、工商年报两篇政策文档。

### 开源发布准备
- 文档集：快速开始、使用指南、部署、架构、FAQ、路线图、发布清单、安全说明；
- `scripts/seed_demo.py`：一键生成虚构演示公司（全年台账/工资/票据匹配/申报/结账/归档/汇算）；
- CHANGELOG、Makefile、GitHub Issue/PR 模板；
- LICENSE 版权人更新为 `snz <274043505@qq.com>`。

## 修复
- 扣缴辅助表「本期减除费用」按 2026 扣缴端「实际申报月份」口径计算；
- 年度汇算输入未提供时不再被默认 0 覆盖（回退台账汇总值）；
- 申报日历描述补充各地差异说明。

## 升级说明

- 无需数据迁移（schema 仍为 v2，未新增数据表）；
- `data/` 已从版本库移除：升级后你本机的 `data/` 保持不变；新环境首次启动会自动创建默认公司；
- 建议发布前备份：`python main.py backup --tag before_upgrade`。

## 验证

- `pytest tests/ -q` → 全绿（700+ 项离线测试）；
- 真实启动 11 页无异常；演示账套脚本可重复执行；
- Markdown 相对链接校验通过；CI（Python 3.11/3.12）通过。

## 已知边界

- 系统只做数据准备、测算与核对，**不代替**电子税务局/扣缴端/公示系统/残联申报；
- 工商年报股东出资、对外投资需人工补充；资产状况为台账估算，需与财务报表核对；
- 残保金申报期限、残联审核流程各地不同，以当地公告为准；
- 单机本地工具定位，暂无多用户权限体系。
