# v1.38.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.38.0`

## 新增：找回后的完整性检查

在「🆘 资料找回」页新增「📊 完整性检查」：

- 公司基本信息；
- 收入/费用台账；
- 员工与工资；
- 发票数据；
- 历史申报补录；
- 申报归档。

给出完整度百分比、需补齐项和对应功能入口，帮助判断“现在能不能继续申报”。

## 新增：历史申报补录

在「🆘 资料找回」页新增「📥 历史申报补录」：

- 逐条新增：所属期、税种、申报日期、税额、状态、备注；
- 自动去重（同所属期 + 同税种）；
- 下载 CSV 模板，批量导入；
- 列表查看、删除；
- 数据保存在本地账套，不访问电子税务局。

## 说明

- 补录用于本地核对与后续申报，不替代电子税务局实际申报；
- 历史申报以电子税务局记录为准；
- 找回后建议立即做备份/交接包。

## 验证

- 全量离线测试 853 项；
- 资料找回三个标签在浏览器/桌面版中正常渲染；
- 官网/下载包/在线演示同步更新。
