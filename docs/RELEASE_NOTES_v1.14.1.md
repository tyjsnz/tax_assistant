# v1.14.1 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.14.1`

## 修复：本地优先时，写台账指令不能被缓存跳过

v1.14.0 的本地优先/缓存上线后发现一个边界问题：

- “收到云图科技 2 万服务费”这类**记收入/费用**的指令，如果之前有相同问答缓存，
  可能直接返回旧回答而没有真正记账。

### 修复

- 收入/支出（`income`/`expense`）指令**禁止命中问答缓存**，每次都执行本地工具；
- 其他查询/测算问题继续使用本地优先与缓存；
- 增加回归测试：同一记账指令连续两次必须记录两笔，不能被缓存跳过。

## 说明

- 记账、算税等写/算操作仍然全部本地确定性执行；
- 缓存仅用于“问答类”内容，且政策版本变化后自动失效。

> ⚠️ 所有回答仅供参考，以主管税务机关核定为准。
