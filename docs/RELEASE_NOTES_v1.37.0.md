# v1.37.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.37.0`

## 亮点：🆘 电脑坏了 / 资料找回

适用于：旧电脑损坏、系统重装、账套误删、交接时资料缺失。

### 5 步找回清单

1. 先确认丢了什么，先不要重复申报；
2. 从电子税务局找回申报记录、完税凭证、财务报表；
3. 找回发票、个税、社保、银行流水；
4. 在新系统重建公司、导入发票/流水、补录历史账；
5. 核对累计数/亏损、继续申报，并开始定期备份。

每步包含：

- 电子税务局/扣缴端/银行的具体操作路径；
- 官方入口链接；
- 系统内对应功能入口（发票归集、设置建公司、报税日历等）；
- 可勾选进度，自动保存；
- 一键下载 Markdown 清单。

## 说明

- 本页只做找回与重建指引，不代替税务机关处理；
- 历史申报以电子税务局记录为准，不要凭记忆重复申报；
- 找回后建议立即做备份/交接包，避免再次丢失。
