# v1.49.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.49.0`

## 改进：扣缴端模板按全部 30 列导出

之前只填写了部分列，其他列留空；现在以税务局模板的 30 列表头为准逐列输出：

| 类别 | 列 |
|---|---|
| 人员 | 工号、姓名、证件类型、证件号码 |
| 本期 | 本期收入、本期免税收入 |
| 社保 | 基本养老保险费、基本医疗保险费、失业保险费、住房公积金 |
| 累计专项附加 | 子女教育、继续教育、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护 |
| 其他扣除 | 个人养老金、企业年金、商业健康保险、税延养老保险、公务交通费用、通讯费用、律师办案费用、公积金和年金调整、西藏附加减除费用、其他 |
| 其他 | 准予扣除的捐赠额、减免税额、协定减免、备注 |

说明：

- 有员工专项附加档案的，按档案月度明细和已生成工资月份累计分摊；
- 系统没有的字段写 0，不会留空导致扣缴端导入异常；
- 完整证件号码仍需导出时临时填写，不落库。

## 验证

- 真实 2026-10 文件：10 人、30 列导出；
- 全量 883 项测试通过。
