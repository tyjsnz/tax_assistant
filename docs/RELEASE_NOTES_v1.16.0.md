# v1.16.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.16.0`

## 亮点：图文操作指引 2.0（自绘、不含官方截图）

新增第 13 个页面「📖 操作指引」，面向零基础用户，先覆盖 3 个高频流程：

1. **增值税及附加税费申报**（小规模纳税人·按季）
2. **个税扣缴申报**（自然人电子税务局扣缴端）
3. **离职员工多申报更正**（扣缴端）

每个流程 5 步，每步包含：

- **自绘菜单路径**（面包屑示意，不复制税务局 UI）；
- **字段/项目说明**：怎么填、注意什么；
- **常见错误**：新手最容易踩的坑；
- **小贴士**；
- 官方入口链接（只外链，不打包第三方页面）。

支持：

- 勾选步骤完成进度；
- 一键导出 **PDF 操作单**（reportlab 中文字体）；
- 离职更正流程可直接跳转「🧯 离职与纠错」配套使用。

## 为什么不用电子税务局截图

- 官方页面通常有版权/转载限制；
- 各省界面不同、改版频繁，截图容易过期；
- 真实截图常含企业名、税号、金额等敏感信息。

因此采用「自绘示意图 + 字段说明 + 官方入口外链 + 用户自行截图备注（后续）」的方式，兼顾小白体验与合规。

## 变更

- 侧边栏 13 个页面；
- 全量离线测试 **795 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 操作指引为自绘说明，非官方页面；实际以当地电子税务局为准。
