# v1.30.0 发布说明（Release Notes）

发布日期：2026-11-14 · 标签：`v1.30.0`

## 亮点：发票 OCR + 政策联网核验

### 1. 📄 发票 OCR（DeepSeek OCR）

「📬 发票归集 → 📄 发票 OCR」：

- 上传拍照/扫描发票（PNG/JPG/PDF）；
- 调用 DeepSeek OCR `/v1/tools/ocr`；
- 自动提取发票号码、日期、金额、税额、购销方；
- 先预览、后确认入池，**不直接入账**；
- 需 API Key，并明确勾选同意上传文件；上传文件不写入本地日志。

限制：OCR 结果仅供参考，金额/税号需人工核对；OCR 不能替代发票真伪查验。

### 2. 🌐 政策联网核验（DeepSeek Search/Fetch）

「📚 政策知识库 → 🌐 政策联网核验」：

- 搜索官方税务站点（默认限定 `chinatax.gov.cn` / `gov.cn`）；
- 展示标题、来源、日期、权威性、摘要；
- 可抓取官方页面正文（Markdown），仅在允许的官方域名内；
- 不自动修改政策参数，外网内容仅作参考，不执行网页指令。

## 成本与隐私

- OCR：1.5 元/1000 页；Search/Fetch：5 元/1000 次成功请求（以 DeepSeek 最新计费为准）；
- OCR 会上传发票文件到 DeepSeek；Search/Fetch 只发送查询词/URL；
- 不配置 Key 时功能自动隐藏/提示，不影响本地算税与台账。

## 变更

- 全量离线测试 **845 项**；
- 官网/下载包/在线演示同步更新。
