# v1.41.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.41.0`

## 1. 待办任务持久化

- 「忽略」的发票任务写入本地账套，跨天保留；
- 可随时在「已忽略任务」里恢复；
- 生成凭证后发票变为已入账，任务自动消失。

## 2. 直接生成凭证

- 任务里选中一张「未入账」发票，点「✅ 直接生成凭证」；
- 自动生成收入/费用台账和记账凭证；
- 发票状态更新为「已入账」；
- 重复/冲突任务不允许直接生成，避免重复入账。

## 3. 自动匹配银行流水

- 任务页点「🔗 自动匹配银行流水」；
- 调用现有评分引擎（方向 + 金额 + 日期 + 对方名称）；
- 生成匹配建议后到「票据与流水」确认入账；
- 与原有自动匹配能力共用，避免重复实现。

## 验证

- 全量离线测试 853 项；
- 浏览器/桌面版任务按钮正常；
- 官网/下载包/在线演示同步更新。
