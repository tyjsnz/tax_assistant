# v1.18.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.18.0`

## 亮点：新手引导 + 首次报税全流程 + 零申报/滞纳金

### 1. 🚀 新手引导（第 14 个页面）

首次打开首页会出现引导入口，5 步完成：

1. **公司信息**：名称、信用代码、地区（决定城建税税率）；
2. **税务基础**：税务登记/税种认定/三方协议/开票方式确认；
3. **第一笔账**：收入/费用/票据录入；
4. **第一次申报**：跳转「首次报税全流程」；
5. **完成**：进入驾驶舱，明确提示 **AI 助手无需 API Key 也能用**。

进度按公司保存，可继续/跳过/重新引导。

### 2. 🆕 首次报税全流程指引

操作指引新增第 6 个流程，覆盖小白最恐惧的“最后一公里”：

- 税务登记、税种认定、三方协议、开票方式；
- 登录电子税务局、核对企业与所属期；
- 按税种找到申报入口；
- 零申报/正常申报填写；
- 提交、缴款、查询与归档。

### 3. 🗓️ 零申报提醒 + 滞纳金试算

首页新增卡片：

- 本季度无收入时提示“零申报也要报”；
- 滞纳金试算：滞纳税款 × 0.05% × 逾期天数（以税务机关核定为准）；
- 一键打开「首次报税全流程」与申报日历。

## 说明

- 系统仍不直连电子税务局（无公开 API、合规风险高），而是把“最后一公里”做成可执行指引；
- 多用户/权限、移动端深度适配暂不做，避免投入产出比过低。

## 变更

- 操作指引 6 个流程、侧边栏 14 个页面；
- 全量离线测试 **801 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 所有指引与试算仅供参考，实际以主管税务机关核定为准。
