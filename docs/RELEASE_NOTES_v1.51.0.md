# v1.51.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.51.0`

## 修复：申报填报导出无反应 / 核对清单在页面内打开

### 桌面版

- 「生成 Excel 申报包」「生成核对清单 Markdown」后，桌面原生窗口对浏览器下载支持不稳定；
- 现在改为：
  - **💾 保存 Excel 申报包到桌面**；
  - **💾 保存核对清单到桌面**；
  - **📂 打开所在文件夹**。

### 网页版

- 核对清单改为**附件下载**（`application/octet-stream`），
  不再在浏览器当前页直接打开 Markdown；
- Excel 申报包继续下载。

## 使用步骤

1. 申报填报 → 选择所属期；
2. 生成申报表；
3. 生成 Excel 申报包 / 核对清单；
4. 桌面版点「保存到桌面」；网页版点「下载」；
5. 到桌面/下载目录打开文件。

## 验证

- 网页实测两个文件均可下载；
- 桌面版保存到桌面可用；
- 全量测试 883 项通过。
