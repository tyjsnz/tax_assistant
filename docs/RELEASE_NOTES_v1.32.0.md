# v1.32.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.32.0`

## 亮点：手机扫码导入报税日历

报税日历页新增「📱 手机扫码导入日历」：

1. 页面生成二维码，指向官网日历页；
2. 手机相机/微信扫码打开；
3. **iPhone**：点「订阅 2026 年日历」使用 `webcal://` 订阅；
4. **Android / 其他**：下载 `.ics`，用系统日历打开；
5. 导入后由手机系统日历提前 3 天提醒。

官网新增：

- `https://tax.flacn.net/calendar.html`（手机导入引导页）
- `/download/tax-calendar-2026.ics`
- `/download/tax-calendar-2027.ics`

## 重要说明

- 扫码导入的是**通用小规模纳税人日历**，不含企业账目、发票、税额等敏感数据；
- 不同手机/日历 App 的导入入口略有差异；
- 日历截止日遇周末顺延，节假日以税务机关公告为准；
- 本地部署若手机无法访问官网，可先下载 `.ics` 再传到手机导入。

## 变更

- 全量离线测试 **847 项**；
- 官网/下载包/在线演示同步更新。
