# v1.46.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.46.0`

## 1. 📤 导出扣缴端「正常工资薪金所得.xls」

位置：员工与工资 → 月度工资表 →「📤 导出扣缴端申报模板」

- 以税务局下载的空白模板为底稿；
- 填入本期工资；
- 导出的 `.xls` 可直接在自然人电子税务局扣缴端申报页导入。

说明：

- 完整证件号码需要临时填写，仅用于本次导出，**不落库**；
- 社保已拆分养老/医疗/失业时按模板分列导出；未拆分时暂并入基本养老保险费并提示；
- 累计专项附加扣除目前无法按模板分项拆分，导出为 0，有专项附加的员工需在模板中补齐。

## 2. 🧾 工资凭证只能生成一次

- 本期工资凭证已存在时，「确认并生成凭证」禁用；
- 重复点击不会新增凭证；
- 如需重做：先点「🗑️ 删除本期工资凭证」，工资行退回草稿，再重新确认；
- 已申报工资行禁止删除凭证。

## 3. 🧾 零申报说明与调整

零申报不再作为主按钮，移到「本月没有发放工资？」说明：

- 零申报指本月**没有实际发放工资、没有应税收入**；
- 有员工且正常发工资：必须按实际申报，即使工资低于 5,000 元、税额为 0，也不是零申报；
- 有员工但确实未发工资：是否零申报以主管税务机关口径为准；
- 本期已有工资表时，不能做零申报。
