# v1.39.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.39.0`

## 新增：🔍 发票查重核对

位置：发票归集 →「🔍 查重核对」

回答两个问题：

1. 这张发票之前是不是已经做账了？
2. 补录/导入时是不是重复了？

### 判断规则

- 发票号码是主键；有发票代码时按「代码 + 号码」判断；
- 无号码发票按销售方 + 购买方 + 日期 + 金额生成内容指纹，指纹相同视为疑似重复；
- 「已入账」= 发票池状态为已入账，或收入台账按发票号码、费用台账按凭证号/备注匹配到；
- 同号码但金额/日期/方向/销售方不一致 → 「信息冲突」，需人工核对；
- 支持按发票号码/代码/销售方查询单张发票；
- 支持导出核对结果 CSV。

### 使用建议

- 补录发票前，先到「查重核对」查一次；
- 显示「未入账」的，到「票据与流水」生成入账凭证；
- 显示「重复录入」的，保留一张、删除多余记录；
- 显示「信息冲突」的，以电子税务局发票查验结果为准。
