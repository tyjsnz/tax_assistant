# v1.10.1 发布说明（Release Notes）

发布日期：2026-11-11 · 标签：`v1.10.1`

## 修复：员工忘记登记离职日期，也能处理投诉后的更正流程

实际场景：员工几个月前已离职，但 HR 没有在系统里改状态，或只把状态改为「离职」却忘记填离职日期。
这种情况下，原系统无法自动扫描“离职后仍在申报”，用户就卡住了。

v1.10.1 增加 **手动更正模式**，不再强依赖离职日期：

### 1. 「手动生成更正方案」

入口：「👥 员工与工资 → 🧯 离职与纠错 → 🛠️ 员工忘记登记离职 / 没有离职日期？手动生成更正方案」

- 选择任意员工（即使状态仍是「在职」、没有离职日期）；
- 指定**离职月份**（该月之后视为误申报），或直接勾选员工在个税 APP 申诉/误申报的**具体月份**；
- 系统照常按累计预扣法逐月重算，生成多缴/少缴个税、企税影响、PDF/Excel 操作单与进度清单。

### 2. 扫描补录提示

- 扫描结果新增「已标记离职但未填离职日期」列表；
- 页面提供快速补录离职日期入口，补录后自动重新扫描。

### 3. CLI / AI 助手

```bash
# 员工未登记离职日期时，手动指定离职月份
python main.py correction-plan --employee EMP000001 --leave-month 2026-02

# 或直接指定需更正月份
python main.py correction-plan --employee EMP000001 --periods 2026-03,2026-04
```

AI 助手工具支持 `leave_month` 参数，可问：“张三 2026-02 离职，但系统没登记，帮我算下要更正多少”。

## 升级说明

- 无需数据迁移；建议先备份。
- 建议处理前先用银行工资流水/考勤/社保减员记录确认真实离职月份，不要直接填“今天”。

## 免责声明

⚠️ 系统只做扫描、测算与操作指引，实际更正申报仍在自然人电子税务局（扣缴端）完成；
结果仅供参考，以主管税务机关核定为准。
