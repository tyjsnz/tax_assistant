# v1.10.2 发布说明（Release Notes）

发布日期：2026-11-11 · 标签：`v1.10.2`

> 在线体验：https://tax.flacn.net ｜ 在线演示：https://tax.flacn.net/app/

## 修复：离职日期不再“自动填今天”，从源头避免漏报

v1.10.1 增加了“无离职日期也能手动更正”的兜底；v1.10.2 进一步从源头收紧：

### 1. 状态改为「离职」必须填写实际离职日期

- 不再自动把离职日期填成“今天”（这会把几个月前的离职错记成今天，导致离职后月份漏更正）；
- 新增/编辑员工、快捷「标记离职」都要求选择离职日期；
- 历史数据若存在「离职但无日期」，仍保留并可在页面补录。

### 2. 工资表不再为缺失日期的离职员工继续生成

原逻辑只看离职日期，日期为空会被视为“未离职”，工资表可能继续生成；
现在只要员工状态是「离职」且没有日期，就不会进入新工资表。

### 3. 首页与结账前检查主动提醒

- 首页驾驶舱新增提醒：列出缺离职日期的员工；
- 结账前检查新增 `employee_leave_date`：状态「离职」但无日期 → WARNING，提示补录；
- 「离职与纠错」仍提供“补录离职日期”和“手动生成更正方案”两个入口。

## 升级说明

- 无需数据迁移；建议先备份。
- 已有「离职但无日期」的历史员工不会丢，补录日期后即可自动扫描；
- 如果确实不知道具体离职日期，请用「手动生成更正方案」按银行流水/考勤/社保减员月份指定。
