# v1.27.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.27.0`

## 亮点：发票查验辅助 + 逐张复核

### 1. 📷 二维码辅助

- 上传发票图片（PNG/JPG）或 PDF；
- 本地解码二维码（OpenCV），显示二维码内容；
- 识别到官方 `chinatax.gov.cn` 域名时提供官方查验入口；
- 非官方域名明确警告：不要输入账号/密码/验证码；
- 二维码解不出时提示手动到官方平台查验。

### 2. 🧾 逐张复核

发票新增：

- **复核状态**：待复核 / 正常 / 红冲 / 作废 / 需人工确认；
- **查验状态**：未查验 / 已查验-正常 / 查验异常；
- **复核备注**、查验时间；
- 在「📬 发票归集 → 🔎 查验复核」逐张保存，对账看板可统计待复核/未查验数量。

### 3. 为什么不自动验真

- 全国查验平台需要登录/验证码，没有公开批量 API；
- 二维码可能是第三方/伪造链接；
- 扫码结果不能替代官方查验结论。

因此系统只做“辅助打开官方入口 + 记录复核结果”，不自动判定真伪。

## 变更

- 新增依赖 `opencv-python-headless`（仅用于二维码解码，缺失时降级为手动查验）；
- 全量离线测试 **834 项**；
- 官网/下载包/在线演示同步更新。
