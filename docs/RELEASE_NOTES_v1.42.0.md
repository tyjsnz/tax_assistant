# v1.42.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.42.0`

## 新增：📥 综合所得申报表导入

位置：员工与工资 →「📥 导入综合所得申报表」

支持从自然人电子税务局/扣缴端导出的：

- `.xlsx` / `.xlsm` 综合所得申报表；
- `.csv`；
- 旧版 `.xls` 请先另存为 `.xlsx`。

### 自动识别

- 姓名；
- 身份证件号码（落库前脱敏）；
- 手机号码；
- 入职/离职日期；
- 本期收入、个人社保、公积金、专项附加扣除、本期税额（仅预览）。

### 导入规则

- 按身份证号优先、姓名其次去重；
- 已存在人员跳过，不覆盖现有档案；
- 缺失入职日期的，用申报所属月 1 日作为参考，可在员工档案修改；
- 只创建员工档案，工资/扣除仍需在「月度工资表」核对。

### 安全

- 文件只在本地解析，不联网、不上传；
- 身份证号只保存脱敏值；
- 日志不记录身份证原文。

- 官网/下载包/在线演示同步更新。
