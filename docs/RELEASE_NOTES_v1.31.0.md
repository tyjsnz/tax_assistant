# v1.31.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.31.0`

## 亮点：🗓️ 报税日历（第 18 个页面）

页面分三块：

### 1. 📌 先看必做

直接告诉新手：

- **每月**：个人所得税扣缴申报、社会保险费申报缴纳（单位部分）；日常记账/发票归集；
- **每季度**：增值税及附加（小规模通常按季）、企业所得税季度预缴、财务报表、印花税；
- **每年**：企业所得税汇算清缴（5/31）、工商年报（6/30）、残保金（多数 6–9 月）、员工个税年度汇算提醒。

并提示：具体以税种认定和主管税务机关通知为准；无员工/无社保/无业务时也要确认是否零申报。

### 2. 📅 当月待办

- 本月申报事项、税款所属期、截止日、剩余/逾期天数；
- 「去处理」直接跳转对应页面；
- 「怎么做（3 步）」给出最短操作路径；
- 可导出本月 `.ics` 日历。

### 3. 🗓️ 全年日历

- 12 个月全部事项表格；
- 标识「每月 / 每季 / 每年」；
- 一键导出全年 `.ics`，导入手机/电脑日历，提前提醒。

## 为什么每月是这两个？

有员工、发工资的公司，通常每月要做：

1. **个人所得税扣缴申报**（工资薪金，按月）；
2. **社会保险费申报缴纳（单位部分）**（含单位部分和代扣个人部分，各地截止日不同）。

增值税/附加、企业所得税预缴、财务报表、印花税通常按季（若税局核定按月则按月）；汇算清缴、工商年报、残保金按年。
