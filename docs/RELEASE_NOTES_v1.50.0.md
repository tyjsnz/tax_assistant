# v1.50.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.50.0`

## 修复：扣缴申报辅助表生成/下载没反应

原因：

- 生成辅助表/Excel 后页面重新运行；
- 标签页回到默认的「员工管理」；
- 结果区和下载按钮被隐藏，看起来像没反应；
- 桌面版原生窗口对浏览器下载支持不稳定。

修复：

- 生成后**不再整页重跑**，当前标签页保持；
- 生成成功立即显示提示和结果；
- 桌面版 Excel 改为：
  - **💾 保存辅助表到桌面**；
  - **📂 打开导出文件夹**；
- 网页版继续使用浏览器下载。

## 使用步骤（桌面版）

1. 员工与工资 → 扣缴申报辅助表；
2. 点「📋 生成辅助表」；
3. 查看主表/员工明细/操作步骤；
4. 点「📊 生成 Excel」；
5. 点「💾 保存辅助表到桌面」；
6. 到桌面找 `扣缴申报辅助表_YYYY-MM.xlsx`。

## 验证

- 网页实测生成后标签不跳、结果可见；
- 桌面版保存到桌面可用；
- 全量测试 883 项通过。
