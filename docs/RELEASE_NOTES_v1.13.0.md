# v1.13.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.13.0`

## 亮点：侧边抽屉式 AI 助手 + 渐进式输出

上一版是居中模态弹窗；v1.13.0 改为更像"AI 副驾驶"的**右侧抽屉**：

- 右下角 🤖 按钮点击后，从右侧滑出抽屉；
- **非模态**：页面仍可滚动/点击，不打断当前操作；
- 回答使用 `st.write_stream` **渐进式输出**，提问后连续出现内容；
- 提交问题后抽屉保持打开，消息自动回到“历史在上、输入在下”的顺序；
- 抽屉内可清空对话、跳转完整 AI 页面、关闭；
- 未配置 DeepSeek Key 时离线回答，任何异常不影响当前页面。

## 建议

- 当前实现是**渐进式渲染**（先取得完整回复再逐段展示），视觉上已接近流式；
- 如果要做到**真正的 token 级实时流式**，需要给 `DeepSeekClient` 增加 SSE 流式接口，
  并改造 Agent 工具循环（工具调用阶段仍非流式，最终回答流式）；
  这属于下一步增强，风险和测试成本更高，建议单独迭代。

## 变更

- 全量离线测试 775 项；
- 官网/下载包/在线演示同步更新。
