# 扣缴端离职更正操作示意图 + 视频脚本

> 🎬 **配套视频教程（2 分钟，含中文字幕与配音）**：https://tax.flacn.net/#correction  
> 📄 **示例操作单 PDF**：https://tax.flacn.net/download/离职多申报更正操作单_示例.pdf

> 配套功能：「👥 员工与工资 → 🧯 离职与纠错」。本指南给零基础用户照着做，
> 也可作为录制 3–5 分钟操作视频的分镜脚本。扣缴端版本不同，菜单文字可能略有差异。

## 一、流程图（文字版）

```text
① 员工离职（HR/老板）
   └─ 离职日期、最后工作日、工资结算、补偿金方案
        │
        ▼
② 系统扫描（智小税）
   └─ 「🧯 离职与纠错」→ 发现“离职后仍在申报”的月份与金额
        │
        ▼
③ 生成《更正操作单》（Excel / PDF）
   └─ 逐月差额、多缴可退/少缴需补、企业所得税影响、九步操作
        │
        ▼
④ 停申报（扣缴端）
   └─ 人员信息采集 → 人员状态改「离职」→ 填离职日期 → 报送
        │
        ▼
⑤ 逐月更正（扣缴端）
   └─ 综合所得申报 → 正常工资薪金 → 选月份 → 更正申报
      → 删除该员工 / 收入改 0 → 重新计算 → 发送申报
        │
        ▼
⑥ 退税/补税（电子税务局）
   └─ 多缴：一般退（抵）税管理 → 误收多缴退抵税
   └─ 少缴：补税 + 滞纳金（日万分之五）
        │
        ▼
⑦ 联动处理
   ├─ 企业所得税：多列工资已扣除 → 纳税调增 / 更正年度申报
   ├─ 社保公积金：减员、多缴退费
   └─ 账务：红冲工资/应付职工薪酬；跨年走以前年度损益调整
        │
        ▼
⑧ 留痕归档
   └─ 离职证明、工资结算单、银行流水、更正截图、退税/补税凭证、
      员工申诉及撤销截图、情况说明
```

## 二、视频脚本（建议 3–5 分钟，录屏 + 旁白）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0:00–0:20 | 封面：智小税官网 / 离职与纠错页 | “员工离职忘了停工资、离职后还在报个税，员工在个税 APP 投诉又撤销——别慌，3 步处理。” |
| 0:20–0:50 | 智小税「员工与工资 → 离职与纠错」扫描结果 | “第一步，先扫描。系统自动找出离职后仍在申报的员工和月份，红色提示就是需要处理的。” |
| 0:50–1:30 | 点击「生成更正方案」，展示差额与企税影响 | “第二步，点生成方案。系统按累计预扣法逐月重算，告诉你多缴多少、能退多少、企业所得税影响多少。” |
| 1:30–2:00 | 导出 Excel / PDF，展示九步操作 | “第三步，导出操作单，打印出来照着做。操作单写到扣缴端具体点哪里。” |
| 2:00–2:40 | 扣缴端录屏：人员信息采集改离职 | “打开自然人电子税务局扣缴端，人员信息采集里把员工状态改成离职，填上离职日期。” |
| 2:40–3:30 | 扣缴端录屏：综合所得申报 → 更正申报 → 删除/改 0 → 发送 | “综合所得申报里选误申报月份，点更正申报，把该员工记录删掉或收入改成 0，重新计算后发送。” |
| 3:30–4:10 | 电子税务局：误收多缴退抵税 | “如果多缴了税，在电子税务局一般退抵税管理里申请退税；少缴的补税并交滞纳金。” |
| 4:10–4:40 | 回系统勾选进度、登记申诉台账 | “每做完一步回来打个勾，避免漏步；员工申诉和撤销记录也在这里留痕。” |
| 4:40–5:00 | 结尾：免责声明 + 官网 | “智小税只做测算和指引，实际更正以扣缴端为准，仅供参考。” |

## 三、录制注意事项

1. 使用**演示账套/虚构数据**录屏，不要出现真实公司名、员工姓名与金额；
2. 扣缴端界面录屏前先确认当地版本菜单名称，字幕以实际界面为准；
3. 视频中不要承诺“必然退税/必然通过”，统一加“以税务机关核定为准”；
4. 建议同时输出 1 分钟竖屏短视频（只讲 3 步 + 入口）用于官网/公众号。

## 四、打印清单（可复制到操作单背面）

- [ ] 已确认离职日期、最后工作日
- [ ] 已停发工资、停做工资表
- [ ] 扣缴端人员状态已改「离职」
- [ ] 已逐月更正申报（含后续月份累计数）
- [ ] 多缴已申请退税 / 少缴已补税
- [ ] 企业所得税已调增或更正年度申报
- [ ] 社保/公积金已减员、退费
- [ ] 账务已红冲/以前年度损益调整
- [ ] 员工申诉已撤销并保存截图
- [ ] 资料已归档（情况说明 + 凭证）

> ⚠️ 系统只做扫描、测算与指引，实际更正申报在扣缴端完成；仅供参考，以主管税务机关核定为准。
