# v1.43.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.43.0`

## 修复：综合所得申报表只导入 8 人

使用真实文件 `昆明霖尚科技有限公司_综合所得申报_202610.xlsx` 验证发现两个问题：

1. **多行表头**
   扣缴端导出表头分 3 行（收入额计算 / 收入、专项扣除 / 基本养老保险费等），
   原解析把数据行误当表头，导致收入取不到、人员识别不全。

2. **脱敏身份证去重错误**
   导出文件身份证为 `5****************2` 形式，同尾号员工被误判为同一人，
   10 人只留下 8 人（修复前第二轮更少）。

### 修复后

- 自动定位真实人员起始行；
- 合并多行表头，正确取到「收入」「基本养老保险费」等列；
- 脱敏身份证不再单独作为去重键，叠加姓名判断；
- 真实文件验证：**10 人全部识别**。

## 新增：逐人确认 + 工资草稿

- 预览表增加「确认写入」勾选框，默认不写入；
- 勾选后才创建员工档案；
- 可同时生成月度工资表草稿：
  - 只写本期收入、个人社保、公积金、专项附加、本期税额；
  - 累计收入/累计税额留 0，需在「月度工资表」核对后再重算；
  - 同一员工同一期间已有工资记录时拒绝覆盖。

## 验证

- 真实文件：10 人识别，10 条工资草稿；
- 全量测试 877 项通过；
- 官网/下载包/在线演示同步更新。
