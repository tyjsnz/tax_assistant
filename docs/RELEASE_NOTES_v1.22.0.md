# v1.22.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.22.0`

## 亮点：⚡ AI 代办（预览 → 确认 → 一键执行）

新增第 16 个页面「⚡ AI 代办」，把重复操作交给本地确定性工具，AI 负责理解与解释，不参与算税。

### 可以自动代办的

1. **工资个税**：按在职员工生成当月工资表（累计预扣、社保公积金按档案）；
2. **票据入账**：预览待匹配发票/流水，生成匹配建议并自动确认 ≥80 分匹配入账；
3. **季度申报**：生成全部申报表、校验、导出 Excel/PDF 并归档；
4. **离职纠错**：扫描离职后仍申报的员工，为每人导出《更正操作单》PDF。

### 关键设计

- **预览后再执行**：先看人数/金额/异常，勾选确认才写入；
- **执行前自动备份**：每次写操作前创建本地备份；
- **明确边界**：不登录电子税务局、不提交申报、不缴款、不开发票、不做社保申报；
- 失败单条不阻塞其他条目，结果可在对应页面复核。

### 为什么不能“全自动报税”

电子税务局没有面向此类工具的公开 API；自动登录/提交/缴款涉及账号安全、验证码、地方差异和合规责任。
因此系统把“能确定的本地操作”自动化，把“必须人工确认的申报提交”留给人，并给出操作指引。

## 变更

- 侧边栏 16 个页面；全量离线测试 **814 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 所有金额与操作仅供参考，实际申报以主管税务机关口径为准。
