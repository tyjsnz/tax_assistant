# v1.54.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.54.0`

## 新增：标准化导出目录 + 资料中心

### 新目录

```text
exports/{公司}/{年}/{月或季度}/{类别}/
```

类别：

- 01_申报表
- 02_工资个税
- 03_发票
- 04_报表台账
- 05_社保
- 06_交接备份
- 99_其他

原则：

- 按**税款所属期**归档，不按操作当天；
- 账套原始数据仍在 `companies/{公司}/` 下集中保存，不按月拆；
- 每次导出自动进入对应目录。

### 资料中心

侧边栏「学习与帮助 → 🗂️ 资料中心」：

- 按年、月/季度、类别、文件名筛选；
- 查看导出时间、大小、SHA-256；
- 选择文件后可直接取用（桌面版保存到桌面，网页版下载）；
- 自动生成 `exports/{公司}/index.json` 索引。

### 旧文件迁移

```bash
python scripts/migrate_exports.py          # 预览
python scripts/migrate_exports.py --apply  # 移动到 _legacy/日期/
```

不会删除旧文件。
