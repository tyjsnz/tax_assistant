# v1.15.2 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.15.2`

## 修复：「存为知识」提示导致抽屉/页面撑开

v1.15.1 已把提示改为紧凑 caption，但部分 Chrome 窗口下仍可能因新增元素导致布局变化。

v1.15.2 彻底改为 **按钮状态反馈**：

- 未保存：`📌 存为知识`
- 保存后自动重跑，按钮变为 `✅ 已存为候选`（禁用）；
- **不再追加 caption / alert / toast 等任何新元素**，抽屉宽度固定 430px，页面不产生横向滚动；
- 鼠标悬停在按钮上仍可看到“可在政策知识库审核发布”的说明。

## 验证

- Chrome 1280×900 实测：点击后 `document.scrollWidth == innerWidth`，抽屉宽度保持不变；
- 全量 790 项离线测试通过。
