# v1.55.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.55.0`

## 新增：📝 申报草稿中心

位置：侧边栏「每月 / 每季必做 → 📝 申报草稿中心」

系统按月/季检查：

| 项目 | 检查内容 |
|---|---|
| 工资表 / 个税扣缴 | 本月是否已生成；能否从上月带出；人员/零工资异常 |
| 社会保险费 | 在职人数、个人社保合计、人员增减提醒 |
| 增值税及附加 | 本季度收入/发票台账是否完整 |
| 企业所得税预缴 | 本季度利润、费用数据 |
| 财务报表 | 本季度台账笔数 |
| 印花税 | 合同台账是否录入 |

每个项目显示：

- 状态：可自动准备 / 需补数据 / 待核对 / 已完成；
- 数据来源；
- 详情和风险提醒；
- 「去处理」入口；
- 工资草稿可一键生成。

## 原则

- **只准备草稿，不自动申报**；
- 增值税、印花税必须用本期数据，不能复制上期；
- 数据为空时提示补录，不把“没有数据”当成零申报；
- 所有金额仍需用户逐项核对。

## 验证

- 浏览器实测 6 个项目正常；
- 全量测试 890 项通过。
