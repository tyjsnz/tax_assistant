# v1.9.0 发布说明（Release Notes）

发布日期：2026-11-11 · 标签：`v1.9.0`

> 在线体验：https://tax.flacn.net ｜ 在线演示：https://tax.flacn.net/app/

## 亮点：让“小白”也能自己处理离职员工的个税申诉

员工离职后忘记停工资、离职后还在申报个税，员工在个税 APP 投诉后又撤销——这是很多小公司会遇到的坑。
**撤销申诉 ≠ 数据已更正**。v1.9.0 在 v1.8.0 的扫描/测算基础上，补齐了 AI 助手、可打印 PDF、零基础指引与官网介绍，
让没有会计基础的人也能照着做完。

### 1. 零基础 3 步走

1. **先扫描**：系统列出“已离职但离职后月份仍在申报”的员工、月份、收入与已预扣税额；
2. **生成方案**：按累计预扣法逐月重算，告诉你多缴（可退）多少、少缴（需补）多少，企业所得税影响多少；
3. **照单操作**：导出 Excel / PDF 操作单，按“九步操作”在扣缴端点哪里、改什么、怎么退税/补税、如何留痕。

### 2. AI 助手直接处理

在「🤖 AI 助手」问：
> “员工离职后还在申报个税，员工在个税 APP 申诉了又撤销，怎么处理？”

助手会识别「离职与申报纠错」意图，调用确定性工具扫描公司数据，列出异常员工并生成更正测算；
未配置 API Key 时也能离线回复处理步骤。

### 3. PDF 操作单（可打印/归档）

《离职员工多申报更正操作单》新增 PDF 版本，包含：
- 员工、离职日期、保留/需更正月份；
- 原/更正后收入、个税、多缴可退/少缴需补；
- 企业所得税影响（小微 5% / 一般 25%）、社保退费参考；
- 逐月更正明细、九步操作、申诉撤销与留痕清单。

### 4. 官网介绍与截图

官网新增「离职员工被多申报？3 步自己处理」区块，包含真实脱敏界面截图与 3 步说明：
https://tax.flacn.net/#correction
