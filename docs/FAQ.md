# 常见问题（FAQ）

## 安装与启动

**Q：Python 版本要求？**
A：3.11+。依赖见 `requirements.txt`（Streamlit、pandas、openpyxl、reportlab、pypdf、requests 等）。

**Q：必须联网吗？**
A：不必。算税、台账、申报表、结账、归档、备份全部离线；只有 AI 问答/政策问答/发票文字理解
需要 DeepSeek Key 与网络，未配置时自动离线确定性回复。

**Q：没有 DeepSeek Key 能用吗？**
A：能。设置页不填 Key 即离线模式，所有确定性功能可用。

**Q：能多人同时用吗？**
A：当前定位单机本地工具，无账号体系。多人/远程使用请部署在内网/VPN，并在反向代理加认证。

## 算税口径

**Q：季度 30 万免税怎么判定？专票算不算？**
A：按**全部销售额（含专票）**判断是否超过季度起征点；未超时普通发票+未开票部分免征，
专票部分不免、按 1% 缴纳；超过则全部按 1%。详见 README 7.1 与政策知识库。

**Q：2026 年为什么不再引用 2023 年第 19 号公告？**
A：《增值税法》2026-01-01 施行后，财政部 税务总局公告 2026 年第 10 号承接优惠；
2023 年第 19 号自 2026-01-01 停止执行（2026 年第 10 号第六条）。系统按期间自动切换依据。

**Q：城建税为什么可能是 5% 或 1%？**
A：城建税按纳税人所在地：市区 7%、县城/镇 5%、其他 1%。在设置 → 企业信息选择地区预设后，
附加税费自动按对应税率计算。

**Q：个税减除费用为什么按“已申报月份”累计？**
A：2026 年自然人电子税务局扣缴端升级：只有实际申报的月份才认可 5,000 元/月减除额度，未申报月份作废。
系统提供「本期零申报」，并提示漏申报风险。

**Q：工资表社保/公积金为什么默认 0？**
A：各地社保/公积金费率与基数差异大，系统不内置比例，按实际缴费金额录入，避免算错。

## 申报与结账

**Q：系统会替我报税吗？**
A：不会。系统生成申报表/辅助表、校验、导出 Excel/PDF，**实际申报与缴款在电子税务局/扣缴端完成**；
系统不做税务鉴证、不代替登录申报。

**Q：结账后想改一笔怎么办？**
A：先反结账（仅最近一期可反结），修改后再结账；结转凭证会自动处理。期间锁会阻止直接改账。

**Q：申报表栏次和电子税务局不一致？**
A：以电子税务局最新表样与主管税务机关口径为准；系统生成的是数据准备与核对参考。

**Q：申报表核对（OCR）识别不出来？**
A：macOS 本机使用 Vision 本地 OCR；纯图片/低清截图识别率有限，可手动粘贴栏次文本核对；
容器/Windows 无本地 OCR 时请手动粘贴或使用 XML/OFD 发票。

## 数据与备份

**Q：数据存在哪里？**
A：`data/companies/{公司}/` 下 CSV；设置页可查看数据目录；不包含任何云数据库。

**Q：API Key 安全吗？**
A：只保存在本地 `data/user_settings.json`（权限 600），界面脱敏显示，不写日志、不进备份。

**Q：怎么换电脑/升级？**
A：`main.py backup` 生成 zip → 复制到新环境 `data/backups/` → `main.py restore --file ... --yes`；
或直接复制整个 `data/` 目录。

**Q：备份包含 API Key 吗？**
A：不包含（不含 `user_settings.json`、上传文件、旧备份/归档）；恢复也不会覆盖 API Key。

**Q：演示数据怎么删？**
A：设置 → 企业信息 → 删除演示公司（软删除）；或 CLI `main.py company-delete --id demo`。
