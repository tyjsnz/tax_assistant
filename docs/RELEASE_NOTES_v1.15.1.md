# v1.15.1 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.15.1`

## 修复：「存为知识」提示撑开页面

v1.15.0 中点击「📌 存为知识」后，成功提示文字较长，在侧边抽屉内可能导致页面横向被撑开 / 遮挡标题。

修复：

- 改为抽屉内紧凑提示（不再用全局 toast）；
- 抽屉增加 `overflow-x: hidden`、最大宽度与自动换行，长文本不再撑宽页面；
- 提示内容精简为「已存为候选 QKxxxx；可在政策知识库审核发布」。

## 验证

- 浏览器实测：`body.scrollWidth == clientWidth`，抽屉宽度固定 430px，无横向溢出；
- 全量 790 项离线测试通过。
