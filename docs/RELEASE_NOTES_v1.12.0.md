# v1.12.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.12.0`

> 在线体验：https://tax.flacn.net ｜ 在线演示：https://tax.flacn.net/app/

## 亮点

### 1. 全局浮动 AI 助手：随时问，不离开当前页面

任意页面右下角常驻 🤖 按钮，点击在当前页弹出对话：

- 问算税、记账、工资个税、离职纠错、申报日历、政策；
- 未配置 DeepSeek Key 时自动离线回答；
- 对话框内可清空对话、跳转完整 AI 页面；
- 提交问题后对话框保持打开，视觉上不会离开当前页面。

### 2. 个税异议申诉台账：筛选 + 导出 Excel

- 按**状态、员工、关键词**筛选；
- 统计待处理/已沟通、已撤销、已更正/已关闭数量；
- 一键导出**当前筛选结果**为 Excel（含汇总 sheet），用于交接与税务核查留档。

### 3. 首页「离职与申诉异常」提醒卡片

驾驶舱新增异常卡片，汇总：

- 离职后仍申报人数/月份、涉及工资、已预扣个税；
- 缺离职日期人数；
- 待处理/已沟通申诉条数；
- 一键跳转「🧯 离职与纠错」处理。

## 变更

- 全量离线测试 **779 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 系统只做扫描、测算与操作指引，实际更正申报仍在自然人电子税务局（扣缴端）完成。
