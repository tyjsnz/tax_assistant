# v1.21.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.21.0`

## 变更：首页只显示「今天先做这 1–3 件事」

v1.20 的待办卡会列 6–8 项，仍可能让新手有压力。v1.21 改为：

- **只显示最紧急的 3 项**：按「逾期 → 今天 → 3 天内 → 7 天内 → 更晚」排序；
- 其余折叠到「查看本月其余 N 项待办」，需要时再展开；
- 每项保留：税款所属期、截止日、剩余/逾期天数、去处理入口；
- 顶部用一句话提示“最紧急：……建议今天处理”；
- .ics 日历导出保留。

## 为什么

对小白来说，“今天先做哪 1–3 件”比“本月全部事项”更能降低启动压力；完整清单仍然可查，但默认不打扰。

## 变更

- 全量离线测试 **809 项**；
- 官网/下载包/在线演示同步更新。
