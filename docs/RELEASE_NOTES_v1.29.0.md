# v1.29.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.29.0`

## 亮点：交接包三件套（加密 / 签收单 / 导入）

### 1. 🔐 交接包加密

- 生成时勾选「加密交接包」并设置密码；
- 输出 `.zip.enc`（PBKDF2 200,000 次 + Fernet）；
- 邮件/网盘传输不必裸奔；
- 导入时输入密码，密码错误给出明确提示。

### 2. 🧾 交接签收单 PDF

自动生成：

- 公司名称/统一社会信用代码；
- 交接包文件名、SHA-256、文件大小、数据表数、记录总数；
- 移交方/接收方签字盖章栏与日期；
- 官方发行标识与免责声明。

可单独下载，随交接包一起归档。

### 3. 📥 交接包导入

- 支持普通 zip 和加密 `.zip.enc`；
- 先检查 `manifest.json` 中的文件 SHA-256，损坏/被篡改会拒绝；
- **导入为新公司**，不覆盖现有账套；
- 自动复制 CSV、归档文件、附件，并切换到新公司。

## 适用场景

- 公司更换代账/财务；
- 迁移到新电脑/新实例；
- 公司注销前留档；
- 交接双方签收、审计留痕。
