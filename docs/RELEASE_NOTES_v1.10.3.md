# v1.10.3 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.10.3`

> 在线体验：https://tax.flacn.net ｜ 在线演示：https://tax.flacn.net/app/

## 修复：手动更正方案改为“选择离职日期，自动带出需更正月份”

反馈：手动生成更正方案里，“离职月份”只能从工资月份里选 2 个，且把王五离职日期改成 2026-06-04 后，
仍需更正的月份显示成 2026-10、11，和实际对不上。

原因是旧版让用户从**已有的工资月份**里挑一个“离职月份”，默认值取倒数第二个月，并不参考真实离职日期。

### 现在

- 手动模式改为 **日期选择器**：直接选择离职日期（默认取员工档案里的离职日期）；
- 系统按该日期**自动计算并带出**：
  - 保留月份（≤ 离职月份）；
  - 应更正月份（> 离职月份，且该员工有工资记录的月份）；
- 切换日期会立即重新计算；也可手动勾选调整需更正月份；
- 可勾选“同时把该离职日期写入员工档案”，下次即可自动扫描；
- 例如王五离职 2026-06-04：系统会显示保留 1—6 月、应更正 7—12 月中存在工资记录的月份，而不是固定 Oct/Nov。

### 说明

* 若员工工资记录本身只有 Oct、Nov 两个月，那么离职 6 月后只剩 Oct、Nov 可更正，这是正常的；
* 更正范围只针对**有工资申报记录**的月份，不会凭空生成没有申报的月份。

## 升级说明

- 无需数据迁移；建议先备份；
- 升级后到「员工与工资 → 🧯 离职与纠错 → 手动生成更正方案」即可看到日期选择器与自动计算。
