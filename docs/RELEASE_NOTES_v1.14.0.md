# v1.14.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.14.0`

## 亮点：本地优先 + 真 SSE 流式 + 问答缓存/反馈

### 1. 不是每个问题都调 DeepSeek

新增本地优先路由：

- 算税、个税、汇算、离职纠错、申报日历、申报核对等**确定性意图**优先本地回答；
- 命中本地答案/工具时直接返回，**不调用 API**；
- 未配置 Key 时完全离线；配置 Key 时只把“需要解释/开放问题”交给模型。

### 2. 真 SSE 流式输出

`DeepSeekClient` 新增 `chat_stream`，按 SSE 增量解析；抽屉内逐段渲染，首字更快。
本地/缓存答案也采用逐字渐进展示。

### 3. 问答缓存与反馈

- 新增 `qa_history`（当前公司账套）：问题、回答、意图、来源、模型、工具调用、反馈、政策版本；
- 相同问题（规范化 + 政策版本一致）命中缓存，直接本地回答，命中次数可统计；
- 回答下方 👍/👎：踩过的回答不再复用；点赞的将成为后续知识库候选；
- 来源标签：📗 本地计算 / ♻️ 本地缓存 / 🤖 AI 流式。

### 4. 为什么这样设计

- **成本**：多数高频问题本地答，API 调用大幅减少；
- **速度**：缓存命中毫秒级；LLM 路径首字更快；
- **可控**：错误回答可被踩掉，不会立即变成“知识”；
- **可演进**：问答历史是下一步“已审核知识库 + 检索注入”的数据基础。

## 变更

- 全量离线测试 **782 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 问答缓存会在政策版本变化后自动失效；所有回答仅供参考，以主管税务机关核定为准。
