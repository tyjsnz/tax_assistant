# 使用指南（11 个页面）

> 系统按「日常记账 → 票据流水 → 工资个税 → 算税 → 申报 → 核对 → 结账 → 归档/备份 → 汇算」
> 组织页面；侧边栏可切换公司（多账套），设置页管理公司与数据。

---

## 1. 🏠 首页驾驶舱

* 企业名片（名称/纳税人类型/统一社会信用代码/主管税务机关/**地区与城建税税率**）；
* 本季度核心指标：不含税收入、增值税、附加税费、合计税费、申报倒计时；
* 申报提醒（按申报日历，季度/月度/年度）、本年累计收入/费用/利润；
* **期间结账卡片**：当前/上月状态、立即结账（先看 9 项检查清单）、反结账；
* 本月工资与个税提醒卡片；收入趋势图；最近业务与快捷入口。

## 2. 📒 台账管理

* 收入台账：客户、含税金额、发票类型（普票/专票/未开票）、业务类别、研发相关；
  自动换算不含税与增值税额，可导出 CSV 供核对；
* 费用台账：类别（工资/社保/房租/办公/差旅/软件订阅/研发材料/折旧/其他）、研发相关标记；
* 研发辅助账：按项目归集六类费用（人员人工/直接投入/折旧/摊销/设计费/其他），自动限额；
* 合同台账：技术合同/买卖合同等，用于印花税申报；
* 表格可直接编辑、删除、CSV 批量导入导出。

## 3. 👥 员工与工资

* **员工管理**：姓名、工号、部门、岗位、入职日期、社保/公积金基数、减除费用方式
  （累计预扣/一次性 6 万）、专项附加扣除明细（子女教育/婴幼儿照护/继续教育/住房贷款或租金/
  赡养老人/大病医疗）；身份证只保存脱敏值；
* **月度工资表**：选择月份 → 生成工资表（在职员工）→ 编辑应发/奖金/补贴/社保/公积金/专项附加/
  其他扣除 → 重新计算个税（累计预扣法，显示累计应纳税所得额/税率/本期应预扣/实发）→
  确认并生成工资凭证（计提 + 发放代扣）→ 到扣缴端申报后「标记已申报」；
  无工资月份可「本期零申报」（保留 5,000 元/月减除额度）；
* **扣缴申报辅助表**：主表 11 行 + 员工明细 + 校验 + 扣缴端操作步骤，导出 Excel；
  实际申报在自然人电子税务局（扣缴端）完成。

## 4. 📥 票据与流水

* 上传数电票（XML/OFD/PDF）与银行流水（CSV/Excel）→ 自动解析去重入池；
* 自动匹配：方向 + 金额（≤5%）+ 日期（≤15 天）+ 对方名称，0–100 分建议；
* 勾选确认入账：自动写收入/费用台账并生成凭证；也可忽略、手动匹配；
* 支持「一键加载示例」体验完整流程。

## 5. 🧮 算税工作台

* 增值税及附加：含税/专票金额 → 免税额度判断、专票部分缴税、附加税费；
  「从台账取数」一键带入；
* 企业所得税：年度测算 / 季度预缴（本年累计利润、研发加计、已预缴）；
* 研发费用加计扣除：六类费用归集 + 其他相关费用限额；
* 印花税：按合同类型汇总，六税两费减半；
* 页面展示计算公式、政策依据、建议会计分录与免责声明。

## 6. 📋 申报填报

* 选期间 →「生成申报表」：增值税及附加、企业所得税预缴（A 类）、财务报表、印花税；
* 逐表查看栏次（栏次/名称/金额/来源/口径）与勾稽校验结果；
* 导出 Excel 申报包（含填报指引 sheet）、核对清单 Markdown；保存草稿 → 确认 → 标记已申报；
* **归档本期申报包**：生成 xlsx + pdf + manifest（SHA-256）并校验；历史归档列表；
* 申报进度与完成清单（个税在扣缴端申报，系统标记状态）。

## 7. 🔍 申报核对

* 上传申报表截图（macOS Vision 本地 OCR）或手动粘贴栏次文本；
* 字段映射 → 与台账重算结果逐栏比对 → PASS/WARNING/ERROR 差异报告；
* 支持修正识别文本/栏次后重新核对；可导出差异报告。

## 8. 📚 政策知识库

* 政策文档（增值税/企业所得税/其他税费/申报流程）检索，标注来源、生效日、最近核验日；
* 支持分类筛选、原文查看、检索命中；「政策时效检查」提示超过 90 天未核验的文档。

## 9. 🤖 AI 助手

* 自然语言问答（算税/记账/工资个税/汇算/政策/申报日历等），工具调用轨迹可见；
* 无 API Key 时自动离线确定性回复；设置页填写 DeepSeek Key 后启用大模型解释；
* 所有算税数字来自确定性工具，模型只负责解释；回答附政策依据与免责声明。

## 10. ⚙️ 设置

* **API 与模型**：DeepSeek Key 填写/测试/清除、模型（deepseek-chat / deepseek-reasoner）、
  base_url、温度、max tokens；
* **企业信息**：多公司管理（新建/编辑/切换/删除）、地区预设（决定城建税 7%/5%/1%）；
* **数据管理**：创建备份（zip + 哈希，不含 API Key）、校验/删除、上传恢复（默认预览，自动安全备份）、
  归档列表与校验；示例数据加载/清空；
* **审计日志**：算税、分录、申报、结账、归档、备份等操作记录；
* **关于**：版本、免责声明、开源许可。

## 11. 📊 汇算清缴

* **年度数据**：从台账汇总全年收入/费用/利润/工资总额/研发费用/预缴税额/月度明细；
  补充数据（业务招待费/广告费/三项经费/人数/资产/预缴/会计利润覆盖/研发加计覆盖）→ 保存 → 计算；
* **纳税调整**：限额类自动项（业务招待费 60%/5‰、广宣费 15%、福利 14%/教育 8%/工会 2%）+
  手工调整清单（罚款、免税收入等，调增/调减）；
* **亏损弥补**：亏损台账（年度/金额/已弥补/剩余/到期）+ 本年度可弥补测算；
* **申报辅助表**：A 类主表 12 行 + 调整明细 + 亏损明细 + 政策依据 + 校验/操作步骤，导出 Excel；
* **检查清单**：收入一致、费用凭证、研发辅助账、亏损台账、预缴核对、小微条件、资料留存、5/31 期限。

## 典型节奏

| 频率 | 做什么 |
|---|---|
| 随时 | 记账、导入票据/流水、员工入职与工资录入 |
| 每月 | 工资表 + 个税计算/确认、扣缴端申报后标记、月结（可选） |
| 每季度 | 算税 → 生成申报表 → 校验 → 导出 → 电子税务局申报 → 标记已申报 → 归档 |
| 每年度 | 1 月前后年度结账、5 月 31 日前汇算清缴、6 月 30 日前工商年报 |

> ⚠️ 系统只做数据准备与核对，不代替电子税务局申报；以主管税务机关核定为准。
