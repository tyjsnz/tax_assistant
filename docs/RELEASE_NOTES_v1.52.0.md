# v1.52.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.52.0`

## 修复：全系统导出下载统一

现象：

- 桌面版部分页面点“下载/导出”没有反应；
- 网页版部分 Markdown/CSV 会在当前页打开，而不是下载。

原因：

- 桌面版 pywebview 原生窗口对浏览器下载支持不稳定；
- 各页面各自调用 `st.download_button`，没有统一兜底。

修复：

- 新增 `ui/components/downloads.py`；
- 所有涉及导出的页面统一调用：
  - 网页版：浏览器下载；
  - 桌面版：**💾 保存到桌面** + **📂 打开文件夹**；
- 覆盖页面：
  - 申报填报；
  - 月度工资表 / 扣缴申报辅助表 / 离职纠错 / 异议申诉；
  - 汇算清缴；
  - 台账管理；
  - 发票归集；
  - 报税日历；
  - 操作指引；
  - 设置备份；
  - 资料找回。

## 使用

桌面版看到「💾 保存到桌面」就表示文件已生成；保存后到桌面打开。
网页版继续点「下载」。

## 验证

- 全量测试 883 项通过；
- 桌面版保存到桌面实测可用。
