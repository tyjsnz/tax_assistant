# v1.26.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.26.0`

## 亮点：定时扫描 + 发票对账看板

### 1. 定时扫描

**打开系统时自动扫描**（默认关闭）：

- 设置最短间隔（默认 6 小时）；
- 可勾选同时拉取邮箱附件；
- 扫描结果用 toast 提示新导入数量；
- 不会阻塞正常使用。

**命令行定时任务**：

```bash
cd /path/to/tax
.venv/bin/python scripts/collect_invoices.py --auto --json
```

可配置到：

- macOS：launchd / cron；
- Linux：cron；
- Windows：任务计划程序。

### 2. 📊 发票对账看板

新增第 3 个 tab：

- 已归集发票、本月新增、待匹配、已匹配/入账；
- **重复发票号**；
- **疑似红冲/作废/负数发票**；
- **跨期发票**（早于本季度）；
- 归集失败记录；
- 跳过/重复文件统计。

> 说明：系统只能统计“已归集”的发票；“未归集”无法从系统外部感知，需与电子税务局全量发票查询对账。
