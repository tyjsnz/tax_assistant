# v1.19.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.19.0`

## 亮点：P1 四项（发票合规、概念解释、税务登记、稽查应对）

### 1. 🧾 发票合规判断（第 15 个页面）

规则式回答小白最常问的三个问题：

- 这张票能不能**入账**？
- 能不能**抵扣增值税**？
- 能不能在**企业所得税前扣除**？

覆盖：专票/普票/数电票、收据/财政票据、白条/无票支出、抬头不是本公司、个人消费/福利、免税项目、跨年度发票等；给出风险等级与说明。**不依赖 AI 猜，不确定事项提示咨询专业人士。**

### 2. 📖 操作指引扩到 8 个流程

新增：

- **税务登记与税种认定**：税务登记/实名 → 税种认定与期限 → 三方协议 → 发票票种 → 首次申报检查；
- **税务稽查/约谈应对**：确认身份与文书 → 准备资料 → 自查风险 → 如实沟通 → 处理结果与整改。

### 3. 📘 小白概念解释

算税工作台、台账管理、申报填报页新增折叠说明：

- 含税/不含税换算公式与例子；
- 权责发生制 vs 收付实现制，跨期收入/费用怎么处理。

## 变更

- 侧边栏 15 个页面、操作指引 8 个流程；
- 全量离线测试 **807 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 发票判断与指引仅供参考，不构成税务意见；以主管税务机关口径为准。
