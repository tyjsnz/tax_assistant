# v1.45.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.45.0`

## 新增：📥 工资空白项填充

适用：已经生成过 0 草稿，或部分工资行是空的，不想删除重来。

位置：员工与工资 → 月度工资表 →「📥 用上月数据填充空白项」

规则：

- 取该员工最近一期工资；
- 只填当前为 **0** 的：应发工资、奖金、补贴、个人社保、个人公积金、专项附加、其他扣除；
- **不覆盖**已填写的非零金额；
- **不动**累计收入、累计税额、实发工资；
- 已确认/已申报工资行不可修改；
- 填完后仍需点「重新计算个税」。

## 使用建议

1. 选择工资月份；
2. 点「用上月数据填充空白项」；
3. 检查金额并修改差异；
4. 点「重新计算个税」；
5. 再确认生成凭证。
