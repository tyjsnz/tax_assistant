## 亮点：离职员工多申报与个税异议申诉处理

员工离职后忘记停做工资、离职后月份仍申报个税，员工在个税 APP 投诉后又撤销——这是不少小公司会遇到的问题。
**撤销申诉 ≠ 数据已更正**。v1.8.0 把「发现 → 测算 → 操作单 → 留痕」做成了系统闭环：

- **异常扫描**：自动找出「已登记离职日期、但离职月份之后仍有工资/个税申报」的员工，
  列出涉及月份、工资、已预扣个税与申报状态；
- **逐月更正测算**：以离职月份为界，离职后月份收入/专项扣除改为 0，按累计预扣法**逐月重算**，
  得出预计多缴（可退）或少缴（需补）个税；
- **联动影响**：估算多列工资的企业所得税调增（小微 5% / 一般 25%）、社保公积金个人部分退费参考；
- **《更正操作单》Excel**：扣缴端逐月更正步骤、电子税务局退（抵）税路径、企业所得税/社保/账务联动、
  申诉撤销路径与留痕清单；
- **个税异议申诉台账**：申诉类型、日期、状态（待处理/已沟通/已撤销/已更正/已关闭）、撤销日期、处理结果；
- **知识库**：《离职员工多申报工资与个人所得税异议申诉处理》政策指引。
