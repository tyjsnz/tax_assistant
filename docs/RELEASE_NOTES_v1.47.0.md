# v1.47.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.47.0`

## 修复：扣缴端模板导出“没有反应”

原因：

- 点击「📤 生成扣缴端模板」后 Streamlit 重新运行；
- 导出区所在的折叠面板重新折叠；
- 生成成功提示和下载按钮被藏起来，看起来像没有反应。

修复：

- 生成成功后导出区保持展开；
- 显示「已生成模板：N 人」；
- 下载按钮保持可见，可直接下载 `正常工资薪金所得.xls`。

## 使用步骤

1. 员工与工资 → 月度工资表；
2. 展开「导出扣缴端申报模板」；
3. 填写完整证件号码；
4. 点「生成扣缴端模板」；
5. 点「下载正常工资薪金所得.xls」；
6. 到扣缴端申报页导入。

## 验证

- 浏览器/打包版实测可生成并下载；
- 全量测试 882 项通过。
