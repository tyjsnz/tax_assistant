# v1.57.0 发布说明（Release Notes）

发布日期：2026-11-28 · 标签：`v1.57.0`

## 新增：📊 财务报表工作台

位置：侧边栏「季度 / 年度 → 📊 财务报表」

### 可录入

- 期初：货币资金、应收账款、存货、固定资产、应付账款、应交税费、其他负债；
- 期末：货币资金、应收账款、存货、固定资产、其他资产、应付账款、应交税费、短期借款、其他负债；
- 实收资本、未分配利润（留 0 自动倒挤）、备注。

### 生成

- 资产负债表（期末 / 年初）；
- 利润表（本期 / 本年累计）；
- 简化现金流量表（按银行流水方向 + 摘要关键词分类）；
- 核对清单：
  - 资产 = 负债 + 所有者权益；
  - 货币资金是否录入；
  - 现金流净增加 = 期末 − 期初；
  - 银行流水是否导入；
  - 应收/应付是否完整。

### 导出

「生成标准 Excel 草稿」输出 4 个工作表：

1. 资产负债表
2. 利润表
3. 现金流量表
4. 核对清单

## 说明

- 仍是草稿，正式报送前需与总账、银行对账单、发票、工资表核对；
- 现金流量表为简化分类，借款/投资/设备等需人工核对；
- 未录入余额时，货币资金仍按台账估算。
