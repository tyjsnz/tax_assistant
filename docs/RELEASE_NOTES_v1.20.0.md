# v1.20.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.20.0`

## 亮点：菜单分组 + 本月/本季度待办 + 日历提醒

### 1. 侧边栏按“使用频率/重要程度”分组

不再 15 个页面平铺：

- **开始**：首页驾驶舱、新手引导；
- **日常记账**：台账管理、票据与流水、发票合规；
- **每月 / 每季必做**：员工与工资、申报填报、申报核对；
- **季度 / 年度**：算税工作台、汇算清缴；
- **异常处理**：离职与纠错；
- **学习与帮助**：操作指引、政策知识库、AI 助手；
- **系统**：设置。

当前页面用主色高亮，减少“不知道从哪下手”的压迫感。

### 2. 首页「本月 / 本季度必做」待办卡

- 按截止日排序；
- 展示税款所属期、截止日、剩余/逾期天数、状态颜色；
- 直接「去处理」跳申报填报/工资个税；
- 打开系统时对逾期/临近事项给出提醒。

### 3. .ics 日历提醒

- 一键导出申报日历到手机/电脑日历；
- 每个事件提前 3 天提醒；
- 解决“系统关闭后无法推送”的限制。

## 提醒能力说明

- 当前是**本地桌面/内网应用**：只能在你打开系统时提醒；
- 关闭后系统级提醒依赖你导入的 `.ics` 日历；
- 如需微信/邮件/短信推送，需要额外服务端与配置，后续可单独评估。

## 变更

- 全量离线测试 **809 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 申报截止日遇周末顺延，节假日以税务机关公告为准。
