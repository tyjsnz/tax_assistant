# v1.23.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.23.0`

## 亮点：AI 对话直接触发「代办确认卡」

不需要先打开「⚡ AI 代办」页：在悬浮抽屉或完整 AI 页面直接说：

- “帮我准备本季度申报”
- “帮我生成本月工资表”
- “帮我把票据匹配入账”
- “帮我扫描离职多申报并导出操作单”

AI 识别到明确动作后，会返回一张**代办确认卡**：

1. 显示预览：人数/待生成数、待匹配发票/流水、申报表数量/合计税额、异常员工/涉及工资；
2. 你勾选“我已核对预览”；
3. 点「⚡ 确认执行」；
4. 执行前自动备份，结果回到对话并可在对应页面复核。

普通问答（“怎么申报”“截止日是哪天”“离职后还在申报怎么办”）**不会**被误判为执行。

## 边界

- 只代办本地确定性操作；
- **不登录电子税务局、不自动提交申报、不缴款**；
- 所有金额与操作以主管税务机关口径为准。

## 变更

- 全量离线测试 **819 项**；
- 官网/下载包/在线演示同步更新。
