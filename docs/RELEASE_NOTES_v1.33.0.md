# v1.33.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.33.0`

## 亮点：报税日历个性化

「🗓️ 报税日历 → ⚙️ 我的申报范围」：

- 按公司实际业务勾选：增值税、企业所得税、财务报表、个税、社保、印花税、工商年报、残保金；
- 设置「有员工/发工资」「缴纳社保」；
- 日历、当月待办、全年日历、导出的 `.ics` 全部按范围过滤；
- 首次使用根据员工情况自动推断，保存后尊重用户选择。

例：

- 没有员工 → 自动隐藏个税月度事项；
- 不缴社保 → 隐藏社保月度事项；
- 不涉及残保金 → 隐藏年度残保金。

> 手机扫码导入的仍是官网**通用**日历（不含企业信息）；个性化日历请用页面内 `.ics` 导出。
