# v1.40.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.40.0`

## 新增：🧾 待生成凭证任务

位置：发票归集 →「🔍 查重核对」→「待生成凭证任务」

自动把以下发票列成待办：

- **未入账**：去「票据与流水」生成凭证；
- **重复录入**：保留一张入账，删除多余；
- **信息冲突**：先核对，不自动入账。

能力：

- 同一张发票只生成一条任务，避免刷屏；
- 显示发票号码、日期、方向、销售方、金额、判断、处理建议；
- 导出待办 CSV；
- 一键跳转「票据与流水」处理。

## 使用建议

1. 先到「查重核对」看总览；
2. 看「待生成凭证任务」；
3. 未入账的到「票据与流水」生成凭证；
4. 重复的删除多余记录；
5. 冲突的以电子税务局查验结果为准。
