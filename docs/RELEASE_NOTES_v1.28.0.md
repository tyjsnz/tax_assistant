# v1.28.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.28.0`

## 亮点：公司账套交接 / 迁移包

### 为什么

数据备份是“给本系统恢复用”的内部格式；公司换代账、迁移其他系统、注销前留档时，
需要一份**对方能直接打开、能核对完整性**的交接包。

### 内容

设置 → 数据管理 → 「📦 公司账套交接 / 迁移包」一键生成：

- `data/`：当前公司全部原始 CSV（不含 API Key/全局设置）；
- `账套汇总.xlsx`：每张表一个 sheet + 交接摘要；
- `archives/`：申报归档文件（可选）；
- `uploads/`：原始附件（可选，可能较大/含敏感信息）；
- `company.json`：公司信息；
- `manifest.json`：文件清单、行数、SHA-256；
- `README.md`：迁移建议与交接说明。

### 适用场景

- 公司更换代账/财务；
- 迁移到其他财务/税务系统；
- 股东、税务检查需要完整账套；
- 公司注销前留档。

### 安全

- 不含 API Key、全局设置、审计日志；
- 可选是否包含原始附件；
- 交接双方可对照 manifest 的记录数与 SHA-256 签收。
