# v1.11.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.11.0`

## 亮点：把「离职与纠错」拆成独立页面，重点更清楚

反馈：个税异议申诉台账、离职扫描、补偿金、操作步骤全挤在一个 tab 里，页面凌乱、找不到重点。

v1.11.0 将其拆为**侧边栏独立页面「🧯 离职与纠错」**，内部 3 个子标签：

1. **🔍 扫描与更正**
   - 扫描离职后仍申报；补录离职日期；手动/自动更正方案；
   - 逐月明细、扣缴端九步操作、勾选式进度清单；
   - Excel / PDF 操作单导出。
2. **💰 离职补偿金测算**
   - 经济补偿金参考（劳动合同法 47 条）；
   - 一次性补偿个税（3 倍社平以内免征、超出单独计税）；
   - 税后到手。
3. **📬 个税异议申诉台账**
   - 申诉类型、日期、状态、撤销日期、处理结果登记与更新。

员工与工资页恢复 3 个 tab，并保留「🧯 离职与纠错」快捷入口；侧边栏可直接进入。

## 设计理由

- **按任务分组**：扫描/更正是一个流程，补偿金是另一个场景，申诉台账是留痕记录，分开后每屏只做一件事；
- **减少横向拥挤**：员工与工资页只保留员工/工资/扣缴辅助三块，避免和纠错流程混在一起；
- **入口不丢失**：员工管理页保留快捷按钮，侧边栏也可直接进入；
- **后续可扩展**：新增申诉类型、补偿金场景直接加到对应子标签。

## 变更

- 页面总数 11 → 12；侧边栏新增「🧯 离职与纠错」；
- 全量离线测试 **775 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 系统只做扫描、测算与操作指引，实际更正申报仍在自然人电子税务局（扣缴端）完成。
