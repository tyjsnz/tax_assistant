# v1.34.0 发布说明（Release Notes）

发布日期：2026-11-15 · 标签：`v1.34.0`

## 修复：社保费在申报填报页找不到入口

## 1. 🏦 新增「社保费」标签

申报填报页新增「🏦 社保费」：

- 按月汇总参保人数、社保/公积金基数、个人代扣社保/公积金；
- 导出 Excel 辅助表；
- 明确操作步骤：核对人员/基数 → 电子税务局社保费申报/社保客户端 → 缴费留存；
- **单位部分费率各地不同，系统不硬编码**，不代替实际申报。

报税日历中社保事项按钮改为「去社保费 →」，点击进入申报填报页后可直接选择「🏦 社保费」标签。

## 2. 申报填报页重新分区

原来一屏堆叠：申报表、导出、归档、进度、指引、年度其他，容易眼花。

现在改为五个标签：

1. **📋 申报表**：期间、生成、逐表核对、导出；
2. **🏦 社保费**：按月汇总、导出、操作步骤；
3. **📈 进度与指引**：申报进度、逐项填报指引；
4. **🗄️ 归档**：申报包归档、校验；
5. **📆 年度 / 其他**：工商年报、残保金。

每个区域职责清楚，先看标签，再看内容。

## 说明

- 社保费不是税，但按月申报缴纳；有员工的单位通常每月都要做；
- 个税扣缴仍是每月；增值税/企业所得税/财务报表/印花税通常按季（以税种认定为准）；
- 系统只做汇总和操作辅助，实际申报/缴费在电子税务局或当地社保客户端完成。
