# v1.53.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.53.0`

## 新增：完整身份证本地保存与自动带出

### 员工档案

- 新增「身份证号（完整，本地保存）」字段；
- 完整号码只保存在本机账套 `employees.csv`，不上传、不写入日志；
- 页面同时显示完整号码，便于核对。

### 工资表

- 月度工资表新增「身份证号」列；
- 有完整号码显示完整号码，没有则显示脱敏号码。

### 扣缴端模板导出

- 导出时自动从员工档案带出完整身份证；
- 缺失的可在导出表格里补填；
- 勾选「把填写的证件号码保存到员工档案」后，下次自动带出。

### 从申报表导入

- 如果申报表里是完整身份证，会自动保存；
- 如果申报表里是脱敏身份证（如 `5****2`），无法还原，
  需要在员工档案或导出表格里补全一次。

## 安全说明

- 数据仅存本地；
- 完整身份证不会发送给 AI、不会上传；
- 建议电脑设置开机密码，并定期备份账套。

## 验证

- 全量测试 884 项通过；
- 官网/下载包/在线演示同步更新。
