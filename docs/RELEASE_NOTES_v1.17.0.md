# v1.17.0 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.17.0`

## 新增

### 1. 操作指引扩到 5 个高频流程

在原有 3 个流程基础上新增：

- **企业所得税季度预缴（A 类）**：确认所属期/小微身份 → 基础信息 → 收入成本利润 → 优惠与亏损弥补 → 提交缴款；
- **企业所得税年度汇算清缴**：年度资料准备 → 基础信息表 → 主表/纳税调整 → 优惠与亏损 → 提交补退税归档。

每个流程仍为 5 步：自绘菜单路径、字段说明、常见错误、小贴士、官方入口。

### 2. 「我的截图备注（仅本地）」

操作指引每一步新增截图备注：

- 上传自己的操作截图 + 文字备注；
- 只保存在**当前公司账套**的本地 `uploads/guide_shots/`；
- 不上传、不跨公司共享、不进入安装包、**不写入导出 PDF**；
- 可随时删除；
- 提醒用户先遮盖企业名称、税号、金额等敏感信息。

## 为什么这样做

电子税务局界面截图有版权、时效、隐私和地域差异问题；因此产品内置“自绘操作地图”，
用户自己的截图只作为本地个性化备注，既满足小白对照需求，又不产生分发风险。

## 变更

- 全量离线测试 **796 项**；
- 官网/下载包/在线演示同步更新。

> ⚠️ 操作指引为自绘说明，非官方页面；实际以当地电子税务局为准。
