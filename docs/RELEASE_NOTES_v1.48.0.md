# v1.48.0 发布说明（Release Notes）

发布日期：2026-11-16 · 标签：`v1.48.0`

## 修复：桌面版点击下载模板没反应

原因：

- 桌面版使用 pywebview 原生窗口；
- 原生窗口对浏览器下载事件支持不稳定；
- `st.download_button` 在网页正常，在桌面版可能没有反应。

修复：

- 桌面版生成模板后显示：
  - **💾 保存到桌面**：直接复制到桌面，文件名 `正常工资薪金所得_YYYY-MM.xls`；
  - **📂 打开导出文件夹**：在 Finder/资源管理器中定位文件；
- 网页版继续使用浏览器下载按钮。

## 使用步骤（桌面版）

1. 生成工资表并核对；
2. 展开「导出扣缴端申报模板」；
3. 填写完整证件号码；
4. 点击「📤 生成扣缴端模板」；
5. 点击「💾 保存到桌面」；
6. 到桌面找到 `正常工资薪金所得_YYYY-MM.xls`；
7. 到扣缴端申报页导入。

## 验证

- 打包版实测保存到桌面成功；
- 全量测试 883 项通过。
