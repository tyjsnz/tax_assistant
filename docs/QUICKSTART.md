# 快速开始（5 分钟）

> 目标：把系统跑起来，并用内置演示账套走一遍「导入 → 记账 → 算税 → 申报 → 结账 → 归档」。

## 1. 安装

```bash
git clone <your-repo-url> tax-agent
cd tax-agent

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

要求 Python 3.11+；无需数据库、无需联网也能算税/记账/申报。

## 2. 生成演示账套（推荐第一次使用）

```bash
python scripts/seed_demo.py --reset
```

会创建演示公司「示例科技有限公司」（虚构数据）：2026 年收入/费用/研发/合同、
3 名员工与 2 个月工资表、示例发票与银行流水匹配入账、季度申报记录、10 月结账、
Q3 申报包归档、数据备份、汇算输入与调整。

## 3. 启动界面

```bash
streamlit run ui/streamlit_app.py
```

浏览器打开终端提示的地址（默认 http://localhost:8501）。
侧边栏「当前公司」选择 **示例科技** 即可看到完整演示数据。

## 4. 走一遍主流程

| 步骤 | 页面 | 操作 |
|---|---|---|
| ① 看台账 | 📒 台账管理 | 收入/费用/研发/合同四个页签，确认演示数据 |
| ② 导入票据 | 📥 票据与流水 | 「一键加载示例」→「自动匹配」→「确认全部建议」（已预演可直接跳过） |
| ③ 算税 | 🧮 算税工作台 | 选季度 →「从台账取数」→ 查看增值税/附加税/所得税 |
| ④ 生成申报表 | 📋 申报填报 | 选期间 →「生成申报表」→ 查看栏次/校验 → 导出 Excel |
| ⑤ 工资个税 | 👥 员工与工资 | 月度工资表 → 重新计算个税 → 确认并生成凭证 → 导出扣缴辅助表 |
| ⑥ 结账 | 🏠 首页 | 「立即结账」→ 查看检查清单 → 确认结账 |
| ⑦ 归档/备份 | 📋 申报填报 / ⚙️ 设置 | 「归档本期申报包」（xlsx+pdf+哈希）；设置页创建/校验/恢复备份 |
| ⑧ 汇算清缴 | 📊 汇算清缴 | 年度数据 → 保存输入 → 计算 → 年度申报辅助表导出 |
| ⑨ AI 助手 | 🤖 AI 助手 | 不填 Key 也能离线问答；设置页填 DeepSeek Key 后可对话 |

## 5. 换成自己的公司

1. ⚙️ 设置 → 企业信息：修改当前公司名称/信用代码/地区（地区决定城建税 7%/5%/1%）；
2. 演示数据不需要时：设置页删除演示公司，或在「🧾 数据管理」清空台账；
3. 日常使用从「👥 员工与工资」「📒 台账管理」「📥 票据与流水」开始录入。

## 6. 配置 DeepSeek（可选）

⚙️ 设置 → API 与模型 → 填写 `sk-...` → 保存 → 测试连接。
Key 只保存在本地 `data/user_settings.json`（权限 600）。不配置时系统自动进入离线模式，
算税、台账、申报、日历、政策检索全部可用。
