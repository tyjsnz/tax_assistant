# v1.11.1 发布说明（Release Notes）

发布日期：2026-11-12 · 标签：`v1.11.1`

## 修复：独立页面拆分后，申诉台账报 `corrections is not defined`

v1.11.0 把「离职与纠错」拆成独立页面时，原 tab 内的局部导入没有带到新拆分出的
`_render_disputes_section()`，导致打开「📬 个税异议申诉台账」提示：

> 申诉台账不可用：name 'corrections' is not defined

### 修复内容

- 在申诉台账函数内补齐 `ledger.corrections` 与 `ledger.employees` 依赖导入；
- 增加 UI 回归测试：进入「离职与纠错 → 申诉台账」时不得出现“不可用”警告，
  空数据下应显示“暂无申诉记录/新增申诉记录”；
- 全部 773 项离线测试通过。

## 升级说明

- 无需数据迁移；升级后刷新页面即可。

> ⚠️ 系统只做扫描、测算与操作指引，实际更正申报仍在自然人电子税务局（扣缴端）完成。
