## 适用条件

在中华人民共和国境内**书立应税凭证、进行证券交易**的单位和个人为印花税纳税人。
应税凭证包括《印花税法》所附《印花税税目税率表》列举的合同、产权转移书据、营业账簿等。

常见税目税率（《印花税法》税目税率表）：

| 税目 | 计税依据 | 税率 |
|---|---|---|
| 买卖合同 | 价款（不含增值税） | 万分之三（0.3‰） |
| 技术合同（技术开发、转让、许可、咨询、服务） | 价款、报酬或使用费 | 万分之三（0.3‰） |
| 建设工程合同 | 价款 | 万分之三（0.3‰） |
| 运输合同 | 运输费用 | 万分之三（0.3‰） |
| 借款合同 | 借款金额 | 万分之零点五（0.05‰） |
| 租赁合同 | 租金 | 千分之一（1‰） |
| 产权转移书据（土地使用权出让/转让、房屋等建筑物和构筑物所有权转让、股权转让、商标专用权/著作权/专利权/专有技术使用权转让等） | 价款 | 万分之五（0.5‰） |
| 营业账簿 | 实收资本（股本）与资本公积合计金额 | 万分之二点五（0.25‰） |
| 证券交易 | 成交金额 | 千分之一（1‰，出让方缴纳） |

## 优惠内容

1. **「六税两费」减半**：增值税小规模纳税人、小型微利企业和个体工商户，减半征收印花税
   （**不含证券交易印花税**），执行期限 2023-01-01 至 2027-12-31（财政部 税务总局公告2023年第12号）。
   本企业为小规模纳税人，应税合同印花税按适用税率 **× 50%** 缴纳。
2. 其他法定免征 / 减征情形（如已缴纳印花税的凭证副本、无息或贴息借款合同、农业保险合同、
   个人出租住房等）按《印花税法》第十二条及现行规定执行。

## 办理方式

- 印花税按**季 / 按次 / 按年**申报，具体纳税期限由主管税务机关确定；本企业按季申报，
  与增值税申报期一致（季度终了后 15 日内）。
- 通过电子税务局「财产和行为税合并纳税申报」或印花税申报模块填报；
- 六税两费减半由系统自动识别减免，无需单独备案。

## 留存资料

- 应税合同原件或副本（含电子合同）；
- 合同台账（合同编号、对方、类型、金额、签订日期）；
- 印花税申报表、完税凭证；
- 享受减免的证明材料（如小规模纳税人身份、小型微利企业判定资料）。

## 注意事项

1. **未列明金额**的应税合同，按实际结算的金额确定计税依据；金额无法确定的，按书立时市场价格确定；
2. **电子合同**（含电子邮件、电子订单等符合书面形式的凭证）同样应缴纳印花税；
3. 技术合同按 0.3‰，但**技术转让合同**中涉及专利权、专有技术使用权转让的部分税目认定，
   以主管税务机关口径为准；
4. 营业账簿仅对**实收资本与资本公积合计金额**计征，0.25‰ 已是减半后的税率，注意不要重复减半；
5. 计税依据**不含增值税**，合同金额为含税价的应先换算；
6. 未按期申报缴纳可能产生滞纳金（按日万分之五），并影响纳税信用；
7. 具体减免与税目认定以**主管税务机关口径为准**。
